# 설문 기반 양적 학위논문 — 표준 수행 절차 체크리스트

> 이 문서는 "논문 내용"이 아니라 **"논문을 수행하는 절차"** 를 다룬다.
> 내용이 아무리 좋아도 절차를 빠뜨리면 학위가 위험해진다.
>
> ⚠️ **세부 규정은 대학·기관마다 다르다.** 아래는 일반적 기준이며,
> **소속 대학원 학칙과 IRB 규정이 항상 우선한다.**

---

## 0. IRB 심의 — ✅ 종결

**연구자 확인 결과, 숭실대학교 경영대학원은 학위논문 제출 시 IRB 면제 확인서를
요구하지 않는다.** 본 연구는 선행 논문에서 타당화된 척도 문항을 그대로 사용하므로,
연구계획서에 그 출처를 근거로 기재한다.

> 소속 대학원 규정이 우선한다. 아래 내용은 **일반적 참고용**으로만 남긴다.

### 왜 반드시 필요한가

「생명윤리 및 안전에 관한 법률」에 따라 **인간대상연구**는 기관생명윤리위원회(IRB)
심의를 받아야 한다. 설문조사는 인간대상연구에 **포함된다**
(사람을 대상으로 의사소통·상호작용을 통해 수행하거나 개인식별정보를 이용하는 연구).

### 결정적인 세 가지

| | 내용 |
|---|---|
| **사전심의 원칙** | 심의는 **자료수집을 시작하기 전에** 받아야 한다 |
| **소요 기간** | 통상 **1개월 이상**. 보완 요구가 오면 더 걸린다 |
| **사후승인 불가 원칙** | 승인 없이 수집한 자료는 **학위논문에 쓰지 못할 수 있다** |

> **지금 설문을 배포하면 안 된다.** 소속 대학원 IRB 일정을 먼저 확인해야 한다.
> 면제(심의면제) 대상인지 여부도 **IRB가 판단**하는 것이지 연구자가 판단하는 것이 아니다.

### 통상 제출 서류

| 서류 | 상태 | 비고 |
|---|---|---|
| 연구계획심의 신청서 | ⬜ | 대학 IRB 지정 서식 |
| **연구계획서** | 🟡 초안 있음 | `docs/00`·`01`·`02`·`03` 에서 발췌 조립 가능 |

| **설문지** | ✅ 있음 | `survey/02_설문지_배포본.md` |

| 연구책임자 이력 | ⬜ | |

### 연구윤리 교육

IRB 신청의 **전제조건**이다. 교육을 안 받으면 심의가 시작되지 않는다.
- 통상 KIRB(국가생명윤리정책원) 또는 CITI Program 온라인 교육
- 소속 대학이 자체 교육을 운영하는 경우도 많다
- **이수증 유효기간(통상 2년)** 확인할 것

## 1. 자료수집 전 (현재 단계)

| 항목 | 상태 | 비고 |
|---|---|---|
| 연구모형·가설 확정 | ✅ | `docs/01` |
| 측정도구 확정 | ✅ | 교수님 검토 완료 |
| IRB 심의 | ✅ **종결** | 숭실대 경영대학원은 면제 확인서 미요구 |
| **기관 승인 (소방서·소방본부 협조)** | ⬜ | 공무원 조직 대상 조사는 통상 기관 협조 공문이 필요하다. IRB 와 별개다 |
| **척도 사용 허락 / 번역본 송부** | 🟡 | Spector 메일 초안 있음 (`docs/초안/`) |
| **번역–역번역 (back-translation)** | ⬜ | WLCS·SCB 를 자체 번안했다. 번역-역번역 절차와 전문가 검토(CVI/CVR)를 거쳤다는 기록이 필요하다 |
| **파일럿 테스트 (사전조사)** | ⬜ | 20~30명 대상. 문항 이해도·소요시간·이상 문항 확인. **배포 후에는 못 한다** |
| **표본크기 산정 근거** | 🟡 | `docs/03` 에 있음 (최소 450 / 목표 600) |
| 소속코드·경력 연속형 | 🟢 | 반영 완료 |
| 마커변수 | ⬜ | **미채택**(2026-09-16). 숭실대 관행상 사용하지 않음 |
| 역방향 문항 R1~R6 | ⬜ | **미채택**(2026-09-17, 지도교수 결정) |
| 주의점검 문항 AC1·AC2 | ⬜ | **미채택**(2026-09-17, 지도교수 결정) |

> **파일럿 테스트를 건너뛰지 마라.** 47문항 중 하나라도 응답자가 오해하면
> 그 변수 전체가 무너진다. 특히 자체 번안한 WLCS 와 자체 제작한 피드백추구 10문항.
