# 설문 배포 전 재검토 안건

**작성일** 2026-09-14 · **상태** 교수님 결재 대기
**배경** 척도 확정 후 원척도 원전을 재대조하는 과정에서, 배포 후에는 되돌릴 수 없는 사항 6건이 확인되었습니다.

> **읽는 법**
> - **A그룹(1~4번)**: 이미 검토를 마치신 사항을 다시 여쭙는 것입니다. **교수님 결정이 필요**합니다.
> - **B그룹(5~6번)**: 척도를 건드리지 않으므로 **추가 승인 없이 반영 가능**합니다. 보고만 드립니다.
> - 각 항목의 **[현행 유지 시 위험]** 은 그대로 두었을 때 심사에서 나올 질문입니다.

## A그룹 — 교수님 결정이 필요한 사항

### 1. 안전시민행동 응답척도: 동의형 → 빈도형 검토

| | 내용 |
|---|---|
| **현행(확정)** | 5점 동의형 (전혀 그렇지 않다 ~ 매우 그렇다) |
| **검토 의견** | 5점 빈도형 (전혀 하지 않는다 ~ 매우 자주 한다) |
| **근거** | 원척도(Hofmann, Morgeson & Gerras, 2003)가 **빈도형**이며, 안전시민행동은 태도가 아니라 **행동 빈도** 구성개념입니다. 동의형은 규범적 응답("당연히 그래야 한다")을 유발해 **천장효과**가 생기기 쉽습니다. |
| **[현행 유지 시 위험]** | "원척도는 빈도형인데 왜 동의형으로 바꿨나?" / SCB 평균이 4.2 이상으로 몰려 분산이 부족하면 **조절효과 검정력이 떨어집니다.** |
| **유지하는 경우의 방어논리** | 4개 척도 응답형식을 통일해 응답자 혼란과 형식 전환 오류를 줄였다고 기술. 다만 천장효과는 한계점에 명시 필요. |

### 2. 통제위치(WLCS) 응답척도: 5점 → 원척도 6점 검토

| | 내용 |
|---|---|
| **현행(확정)** | 5점 Likert (타 척도와 통일) |
| **검토 의견** | 원척도대로 6점 유지 |
| **근거** | Spector(1988)는 **의도적으로 중립 중간점을 두지 않았습니다**(방향 선택을 강제). 5점으로 바꾸면 중간점이 생겨 **중앙집중 응답**이 늘고, 내적·외적 구분력이 떨어질 수 있습니다. 보고된 α = .83도 6점 기준입니다. |
| **[현행 유지 시 위험]** | "원척도 응답형식을 왜 바꿨고, 그 영향은 검토했나?" |
| **참고** | 척도 간 형식이 달라지는 것은 오히려 **공통방법편향(CMV)의 절차적 통제**로 설명할 수 있습니다(Podsakoff et al. 권고). 즉 6점 유지가 단점이 아니라 장점으로 서술 가능합니다. |

### 3. 지각된 실책관리풍토: 8문항 유지 여부 + **이중질문 문항 분리**

| | 내용 |
|---|---|
| **현행(확정)** | 8문항 |
| **검토 의견** | 문항 수는 8문항 유지 가능. 다만 **이중질문(double-barreled) 문항 점검**이 필요합니다. |
| **해당 문항 예** | Q36 "실수는 **비난보다** 문제해결의 기회로 받아들여진다" — '비난하지 않음'과 '기회로 활용함'은 별개 사안입니다. Q41도 "처벌하기보다 ~ 기회로 활용" 형태로 동일 구조입니다. |
| **근거** | 이중질문은 응답자가 두 요소에 다르게 동의할 때 **어느 쪽에 답한 것인지 알 수 없어** 문항 신뢰도와 타당도를 동시에 훼손합니다. |
| **권고** | 문항 수를 늘리지 않고 **문구만 단문화**하면 승인 부담이 적습니다. 예: Q36 → "실수가 발생하면 비난하지 않고 문제해결에 집중한다" |

### 4. 안전시민행동 문항 수: 6차원 × 2 = 12문항 유지 여부 ★ 통계적으로 가장 중요

| | 내용 |
|---|---|
| **현행(확정)** | 6차원 × 2문항 = 12문항 |
| **검토 의견** | ① 6차원 × 3문항 = 18문항으로 확대, 또는 ② 12문항 유지 + **분석 전략 사전 확정** |
| **정확한 문제** | 차원당 2문항이어도 6요인을 상관시킨 모형은 **형식적으로 식별됩니다**(12지표 기준 df = 39, 과대식별). "수학적으로 불가능"한 것이 아닙니다. 실제 문제는 **추정 불안정성**입니다 — Heywood case(음의 오차분산), 수렴 실패, 표준오차 폭증이 빈발합니다. 또한 2문항 척도의 α는 문항간 상관의 Spearman-Brown 변환에 불과해, 문항간 r = .50이면 α = .67로 **.70에 미달**합니다. |
| **원저자 선례** | Hofmann et al.(2003) **본인들도** 하위척도 간 평균 상관이 높아 6차원을 분리하지 않고 **단일 총점을 사용**했습니다. |
| **12문항 유지 시 권고** | 6요인 1차 CFA를 **주 분석으로 삼지 않고**, ⓐ 단일 총점 또는 ⓑ 차원별 2문항 평균을 지표로 하는 **2차 요인 모형**으로 사전 확정. 이를 3장에 미리 기술하면 "해보니 안 돼서 바꿨다"는 인상을 피할 수 있습니다. |
| **[현행 유지 + 무대책 시 위험]** | 6요인 CFA가 수렴하지 않거나 판별타당도(AVE > 요인상관²)를 통과하지 못해 **4장을 다시 써야 할 수 있습니다.** |

### 8. 통제위치(WLCS) 문항의 소방 조직 부적합 ★ 자체 평가 critical

| | 내용 |
|---|---|
| **진행 상황** | ✅ **일부 이미 반영됨** — 교수님이 Q15·Q17·Q19·Q20·Q22 를 다듬으셨다 ('직장(자리)' → '일자리', '구성원' → '직원' 등). 아래는 **남은 항목**이다. |
| **남은 문항** | Q13 "돈을 버는 것은 주로 행운(재수)의 문제이다" · Q19 "**큰돈을 버는 것은**…" · Q23 "**돈을 많이 버는** 사람과 적게 버는 사람의 주된 차이는 운이다" — **금전 관련 3문항** |
| **문제** | 소방공무원은 **호봉제**이고 이미 **임용된 상태**입니다. "좋은 직장을 얻으려면 배경이 있어야 한다"는 문항이 재직 중인 공무원에게 어떤 의미인지 불분명합니다. |
| **위험** | 응답 분산이 사라지면(전원 중간값 응답) 해당 문항이 요인 추출에 기여하지 못하고, 외적통제 척도의 신뢰도가 무너집니다. 심사에서 **반드시 나오는 질문**입니다. |
| **선택지** | ① 직무 맥락으로 문구 조정 (예: "승진은 대체로 운의 문제이다" 유지, 금전 문항을 조직 내 처우·보직으로 치환) ② 원문 유지 + 분산 소실 시 문항 제거 후 14문항 사용을 **사전 확정** |
| **비고** | 원척도 수정은 Spector 교수 회신을 받아 근거로 삼는 것이 안전합니다 |

## B그룹 — 승인 없이 반영 가능 (보고 사항)

### 5. 마커변수(marker variable) 1~3문항 추가

- **목적**: 공통방법편향(CMV)의 **통계적 통제**
- **이유**: 본 연구는 모든 변수를 동일 응답자·동일 시점 자기보고로 측정합니다. 마커변수가 없으면 CMV 검증이 **Harman 단일요인 검정**에 갇히는데, 이는 현재 가장 약한 방법으로 평가되어 심사에서 자주 지적됩니다.
- **요건**: 연구 변수들과 **이론적으로 무관한** 문항일 것 (예: 심미적 선호, 일반적 성향 문항)
- **비용**: 문항 1~3개. 척도를 전혀 건드리지 않음
- **⚠️ 배포 후에는 추가 불가**

### 6. 소속 119안전센터(팀) 식별 문항 추가

- **목적**: 지각된 실책관리풍토의 **분석수준 방어**
- **이유**: 본 연구는 '지각된' 실책관리풍토로 조작적 정의하여 개인 수준 분석이 정당합니다. 다만 심사에서 "그래도 집단 내 응답 유사성은 확인했나"라는 질문이 나올 경우, **ICC(1)을 계산할 소속 정보 자체가 없으면 답변이 불가능**합니다.
- **형태**: 무기명 유지를 위해 실명이 아닌 **소속 코드**(예: 관할서-센터 번호)로 수집
- **⚠️ 배포 후에는 소급 수집 불가**

### 7. 직무경력 연속형 병기 (추가 보고)

| | 내용 |
|---|---|
| **현행(확정)** | Q5 를 3구간 범주형으로만 측정 |
| **검토 의견** | "( )년 ( )개월" 연속형 문항을 **병기** (범주형 문항은 그대로 유지) |
| **이유** | 절단점 5년·15년에 대해 "다르게 나눴으면 결과가 달랐을 것"이라는 반론이 예상됩니다. 대안 절단점으로 재분석하는 **민감도 분석**이 가장 강력한 방어인데, 범주형만 수집하면 이 분석이 **영구히 불가능**해집니다. |
| **부담** | 문항 1개 추가. 척도는 건드리지 않음 |

> 관련 상세: `docs/07_직무경력_절단점_근거.md`

### 7-1. 주의점검 문항(attention check) 1~2개 추가 ★ 분석계획이 이미 전제하고 있음

- **문제**: 분석계획의 사전 확정 제외기준에 "주의점검 문항 오답자 제외"가 들어 있는데,
  **설문에 주의점검 문항이 없습니다.** 사전분석계획서가 자기 데이터로 실행 불가능한 상태입니다.
- **예시**: "이 문항은 응답 성실도 확인을 위한 것입니다. '보통이다'(③)를 선택해 주십시오."
- 척도를 건드리지 않으므로 **재승인 불요**

### 7-2. 연령 연속형 병기

- 분석계획의 제외기준(경력 > 연령−18 인 불일치 응답 제외)이 **연령 구간형으로는 계산 불가**합니다.
- "만 ( )세" 한 줄 추가

### 7-3. 온라인 설문이면 응답 소요시간 기록 설정

- 불성실 응답(과속 응답) 제외 기준이 분석계획에 있으나, 소요시간이 기록되지 않으면 적용 불가

2. 번역본에 저작권 문구 표기 — `© 1988, Paul E. Spector`
3. 번역자 이름과 연도 명기

공식 한국어판이 배포 목록에 없으므로 본 연구의 자체 번안에 이 의무가 **실제로 발생**합니다.

> **제안**: 저자에게 메일을 보내면서 **내적·외적 분리 채점의 타당성**에 대한 의견도 함께 여쭙는 것이 좋겠습니다. 회신을 받으면 부록에 첨부할 수 있고, 이는 아래 최대 쟁점의 강력한 방어 자료가 됩니다. (비용 0원, 소요 10분)

### 최대 쟁점: WLCS 내적·외적 분리 채점

본 연구는 내적·외적 통제위치를 **독립된 두 변수**로 사용합니다. 그런데 원척도는 **단일차원**으로 개발되어, 내적 문항을 역채점한 뒤 총점 하나를 산출하는 것이 개발자의 공식 채점법입니다(고득점 = 외적).

분리 채점이 방어되려면 다음 세 가지가 모두 필요합니다.

| | 필요 근거 | 상태 |
|---|---|---|
| ① | Macan, Trusty & Trimble (1996) — 2요인 구조를 지지하며 **하위척도 분리 산출을 명시적으로 권고** | 확보 (DOI 확인) |
| ② | Oliver, Jose & Brough (2006) — 2요인도 적합도 미달, 3요인이 최우수라는 **불리한 근거를 선제적으로 수용** | 원문 PDF 확보 필요 |
| ③ | **본 표본에서 1요인 / 2요인 / 3요인 경쟁모형 CFA 비교** | 자료수집 후 실시 |

③이 없으면 ①만으로는 방어되지 않습니다. 분석계획서에 경쟁모형 비교를 **사전 명시**해 두었습니다.
