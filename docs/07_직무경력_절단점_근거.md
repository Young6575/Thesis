# 직무경력 3구간 절단점(5년 / 15년)의 근거

**쟁점** 심사에서 "왜 하필 5년과 15년인가"는 반드시 나온다.
조절변수 두 개 중 하나의 조작적 정의가 근거 없이 떠 있으면 조절효과 결과 전체가 흔들린다.

## 절단점 근거는 법령 하나에만 의존하지 않는 편이 낫다

법령 수치를 확인하더라도, 그것만으로 5년·15년을 정당화하기는 약하다.
승진소요최저근무연수는 **최저 요건**일 뿐 실제 승진 시점이 아니기 때문이다.
아래 네 가지를 **함께** 제시하는 것이 가장 방어력이 높다.

### 근거 ① 제도적 근거 — 승진 체계상의 단계

누적 최저근무연수를 기준으로 하면 경력 구간이 자연스럽게 나뉜다.
법령 수치 확인 후, 5년·15년이 **어느 계급 전환점에 대응하는지**를 3장에 명시한다.

### 근거 ② 경험적 근거 — 소방청 통계연보의 경력 분포

- 출처: 소방청 『소방청 통계연보』 (연도별) — 계급별·경력별 인원 분포 수록
- 활용: 모집단 분포의 3분위(tertile)에 가깝게 구간을 설정했다고 기술하면
  "임의로 나눴다"는 지적을 막을 수 있다
- ⚠️ 이 환경에서 통계연보 원문을 확보하지 못했다. **선생님이 소방청 홈페이지에서 직접 확인 필요**

### 근거 ③ 이론적 근거 — 이미 확보됨

`docs/04_이론적배경_문헌노트.md` 에 정리되어 있다.

| 구간 | 이론적 특성 | 근거 문헌 |
|---|---|---|
| **≤5년 (저경력)** | 사회화 진행기. 역할 스크립트가 미확립되어 **상황강도가 약하고 개인 특성이 강하게 발현**된다. 신규 진입자 재해율 급등 구간 | Morrison (1993) 사회화 · Tett & Burnett (2003) 상황강도 · Bena et al. (2013) |
| **6–15년 (중간경력)** | 현장 숙련 확보 + 조직 내 역할 확립. 수행이 정점에 이르는 구간 | Ng & Feldman (2010, 2013) 재직기간–수행 비선형 |
| **≥16년 (고경력)** | 위험 둔감화(risk habituation), 통제환상 누적. 지휘·멘토링 역할 전환 | Ng & Feldman (2013) 정체·감퇴 |

이 구조가 **H5-2의 역U자 예측**(중간경력에서 b경로 최강)과 직접 맞물린다.

### 근거 ④ 방법론적 보강 — 민감도 분석 ★ 이것이 가장 강력하다

절단점을 어떻게 잡든 "다르게 잡았으면 결과가 달랐을 것"이라는 반론은 남는다.
**대안 절단점으로 재분석하여 결과가 유지됨을 보이면** 이 반론이 원천적으로 차단된다.

`docs/03_분석계획.md` 에 다음을 추가할 것:

```r
# ---- 직무경력 절단점 민감도 분석 ----
# 주 분석: ≤5 / 6-15 / ≥16 (사전 확정)
# 대안 1 : 표본 3분위(tertile) 분할
# 대안 2 : ≤3 / 4-10 / ≥11  (다른 제도적 분기)
# 세 가지에서 H5 계열의 방향과 유의성이 유지되는지 보고한다.
for (cut in list(c(5,15), quantile(dat$tenure_yr, c(1/3,2/3)), c(3,10))) {
  dat$grp <- cut(dat$tenure_yr, breaks = c(-Inf, cut, Inf), labels = c("저","중","고"))
  # ... 다집단 SEM 재추정, 경로계수와 LRT 를 표로 축적
}
```

> **경력을 연속변수로도 측정해 두는 것이 안전하다.**
> 현재 설문 Q5 는 **3구간 범주형으로만** 묻고 있어, 민감도 분석에 필요한
> 실제 연수 데이터가 수집되지 않는다. 배포 전에 **"총 근무경력: ___년 ___개월"**
> 연속형 문항을 함께 넣으면 대안 절단점 검정이 가능해진다.
> 범주형만 남기면 이 분석은 **영구히 불가능**하다.

## 권고 — 설문 배포 전 반영할 것

Q5 를 다음과 같이 **연속형 + 범주형 병기**로 바꾼다. 분석 자유도가 크게 늘고,
범주형 응답이 있으므로 기존 설계도 그대로 유지된다.

```
Q5. 귀하의 소방 분야 총 근무경력은 얼마입니까?
    ( ______ )년 ( ______ )개월
```

→ 분석 시 연구자가 3구간으로 범주화한다. (설문에서 미리 나눌 필요가 없다)

이 변경은 척도 문항을 건드리지 않으므로 **교수님 재승인 없이 반영 가능**하다고 판단되나,
`docs/06_교수님_재승인_안건.md` 에 함께 보고하는 것을 권한다.
