# 용어사전 — 이 프로젝트에서 나오는 말들

> 통계·프로그래밍 용어를 쉬운 말로 풀어 둔 것.
> 대화 중 모르는 말이 나오면 여기서 찾으면 된다.

---

## 도구·파일 관련

| 말 | 쉬운 뜻 |
|---|---|
| **R** | 통계 계산 프로그램. 엑셀보다 정교한 계산을 할 수 있다. 무료 |
| **R 스크립트** | R에게 시킬 계산 순서를 적어둔 파일. **엑셀 수식을 미리 짜두는 것**과 같다 |
| **git / 저장소** | 파일의 모든 수정 이력을 남겨두는 보관함. 잘못 고쳐도 되돌릴 수 있다 |
| **커밋** | "여기까지 저장" 하고 도장 찍는 것 |
| **푸시** | 저장한 것을 인터넷(GitHub)에 올려 백업하는 것 |
| **JSON / CSV** | 문항 목록을 컴퓨터가 읽기 좋게 정리해둔 파일 형식. CSV는 엑셀로 열린다 |
| **스크립트를 돌린다** | 적어둔 계산 절차를 실행한다 |
| **에이전트** | 특정 역할만 맡는 AI 조수. 이 프로젝트엔 3명 (인용검증·문헌탐색·심사검토) |
| **스킬 (`/명령어`)** | 자주 하는 작업의 순서를 적어둔 것. `/모형점검` 처럼 부르면 그 절차대로 한다 |

## 연구 설계 관련

| 말 | 쉬운 뜻 | 이 연구에서는 |
|---|---|---|
| **독립변수 (IV)** | 원인이 되는 것 | 통제위치 |
| **종속변수 (DV)** | 결과가 되는 것 | 안전시민행동 |
| **매개변수 (M)** | 원인과 결과 **사이를 잇는 다리** | 피드백 추구행동 |
| **조절변수** | 영향의 **크기를 바꾸는** 제3의 요인. 같은 비료를 줘도 땅이 좋으면 더 잘 자라는데, 그 '땅' | 지각된 실책관리풍토 · 직무경력 |
| **통제변수** | 결과에 영향을 줄 수 있어서 **미리 걷어내는** 것 | 성별·연령·계급 등 |
| **경로 (a경로 / b경로)** | 원인→다리 가 a경로, 다리→결과 가 b경로 | |
| **매개효과** | 원인이 다리를 거쳐 결과에 가닿는 것 | |
| **조절된 매개** | 그 다리를 건너는 효과가 조절변수에 따라 달라지는 것 | |

### 이 연구의 변수 이름

| 줄임말 | 본딧말 |
|---|---|
| **LOC** | 통제위치 (Locus of Control) |
| **INT / EXT** | 내적통제위치 / 외적통제위치 |
| **FSB** | 피드백 추구행동 (Feedback-Seeking Behavior) |
| **PFSB / NFSB** | 긍정적 / 부정적 피드백 추구행동 |
| **EMC** | 실책관리풍토 (Error Management Climate) |
| **SCB** | 안전시민행동 (Safety Citizenship Behavior) |

## 설문 관련

| 말 | 쉬운 뜻 |
|---|---|
| **문항** | 설문의 질문 한 개 |
| **지시문** | 문항들 앞에 붙는 안내 문구. "다음은 ○○에 대한 질문입니다" |
| **척도** | 한 가지 개념을 재기 위한 문항 묶음. "통제위치 척도 16문항" |
| **원척도** | 외국 학자가 처음 만든 원본 척도 |
| **번안** | 원척도를 한국어로 옮기고 우리 상황에 맞게 다듬는 것 |
| **5점 리커트** | ①전혀 그렇지 않다 ~ ⑤매우 그렇다 로 답하는 방식 |
| **역채점(역문항)** | "나는 게으르다" 처럼 **반대로 진술된 문항**. 점수를 뒤집어 계산한다. 대충 답하는 사람을 걸러내는 장치 |
| **마커변수** | 연구와 **아무 상관 없는** 문항을 일부러 넣는 것. 응답자가 습관적으로 답하는 정도를 재서 보정하는 데 쓴다 |
| **주의점검 문항** | "이 문항은 ③을 고르세요" 같은 것. 안 읽고 찍는 사람 걸러내기 |
| **파일럿 테스트(사전조사)** | 본 조사 전에 20~30명에게 미리 돌려보는 것 |

## 통계 관련

| 말 | 쉬운 뜻 |
|---|---|
| **신뢰도 (알파, α)** | 같은 개념을 재는 문항들이 **서로 비슷하게 움직이는 정도**. 보통 .70 이상이면 합격 |
| **타당도** | 재려던 걸 **제대로 재고 있는지** |
| **요인분석 / CFA** | 문항들이 정말 의도한 대로 묶이는지 확인하는 분석 |
| **판별타당도** | 서로 다른 변수가 **정말 다른 것인지** 확인하는 것. 너무 비슷하면 사실상 한 변수다 |
| **상관** | 두 변수가 함께 움직이는 정도 |
| **부트스트랩** | 자료를 수천 번 다시 뽑아보며 결과가 안정적인지 확인하는 방법 |
| **SEM (구조방정식)** | 여러 변수의 인과 관계를 한꺼번에 검증하는 분석 |
| **다집단 분석** | 집단(예: 경력 3구간)별로 결과가 다른지 비교하는 것 |
| **공통방법편향 (CMV)** | 한 사람이 한 번에 다 답하다 보니 생기는 **인공적인 상관**. 실제보다 관계가 커 보인다 |
| **묵종편향** | 내용과 상관없이 자꾸 "그렇다" 쪽으로 답하는 경향 |
| **천장효과** | 다들 높은 점수로 몰려서 차이가 안 보이는 현상 |
| **HARKing** | 결과를 본 **뒤에** 가설을 만들어 붙이는 것. 연구부정으로 본다 |
| **사전등록** | 자료를 보기 **전에** 분석 계획을 못박아 두는 것 |

## 절차 관련

| 말 | 쉬운 뜻 |
|---|---|
| **IRB (기관생명윤리위원회)** | 사람 대상 연구가 윤리적으로 문제없는지 심사하는 기구. **설문조사도 대상이고, 자료 모으기 전에 승인받아야 한다** |
| **인간대상연구** | 사람에게 묻거나 관찰하는 연구. 설문조사가 여기 해당 |
| **연구윤리 교육** | IRB 신청하려면 먼저 들어야 하는 온라인 교육 |
| **연구대상자 설명문·동의서** | 참여자에게 연구 내용·위험·권리를 알리고 동의를 받는 문서 |
| **Crossref / DOI** | 논문이 실제로 존재하는지 확인하는 국제 데이터베이스. DOI는 논문의 주민등록번호 |
| **KCI** | 한국연구재단이 운영하는 **국내 논문 데이터베이스** |
| **Spector** | 통제위치 척도(WLCS)를 만든 미국 교수. 번역본을 보내달라는 조건을 걸어놨다 |
