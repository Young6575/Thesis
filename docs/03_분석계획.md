## 0. 분석 전체 흐름 (Analysis Pipeline)

```
[0] 자료 수집 종료
      ↓
[1] 자료 정제  ─ 불성실응답 제거 → 결측치 처리 → 이상치 진단 → 역채점 → 정규성 점검
      ↓
[2] 표본 기초통계 ─ 인구통계 빈도 · 무응답 분석 · 대표성 점검
      ↓
[3] 타당성 검증 ─ (3-1) 탐색적 요인분석 EFA  → (3-2) 확인적 요인분석 CFA(경쟁모형)
                  → (3-3) 수렴타당도 AVE·CR  → (3-4) 판별타당도 Fornell-Larcker·HTMT
      ↓
[4] 신뢰도 ─ Cronbach α · McDonald ω · 복합신뢰도 CR · 문항-총점 상관
      ↓
[5] 공통방법편향 ─ Harman 단일요인 → CFA marker technique → ULMC
      ↓
[6] 기술통계 · 상관분석 · 다중공선성(VIF) · 군집효과(ICC) 점검
      ↓
[7] 가설검증 ─ (7-1) 측정모형 → (7-2) 구조모형 → (7-3) 매개(부트스트랩 5,000)
               → (7-4) 조절(평균중심화·상호작용항) → (7-5) 조절된 매개(index)
               → (7-6) 직무경력 3집단 다집단 SEM(측정동일성 선행)
      ↓
[8] 강건성 검증 ─ 대안모형 · 역인과모형 · 곡선효과(탐색) · 군집강건 표준오차
```

**각 단계에서 사전 확정된 판단 규칙이 있으며, 아래 각 절에 수치로 기술한다.**

## 1. 자료 정제 절차 (Data Screening)

### 1.1 분석 대상 제외 기준 (사전 확정)

다음 기준 중 **하나라도** 해당하면 해당 응답을 분석에서 제외한다.
제외 건수와 사유를 논문 4.1절에 **표로 반드시 보고**한다(제외 절차의 투명성이 곧 방어력이다).

| No. | 기준 | 구체적 판정 규칙 | 근거 |
|---|---|---|---|
| **C1** | 연구대상 부적합 | 소방공무원이 아닌 응답(행정직·의무소방 등), 화재진압·구급 외 직렬 | 연구대상 정의 |
| **C2** | 필수문항 무응답 | 척도 46문항 중 **결측 5개 이상**(10.9% 초과) | §1.2 |
| **C3** | 불성실 — 직선 응답(straight-lining) | 척도 46문항 **전체 표준편차 = 0** 또는 **동일 응답 연속 15문항 이상** | 아래 주① |
| **C4** | 불성실 — 무선 응답(careless) | **개인별 문항-총점 상관(psychometric antonym/synonym)** 또는 `careless` 패키지의 **Mahalanobis D² 상위 1%** ∧ **LongString ≥ 15** 동시 충족 | 아래 주② |
| **C5** | 응답 소요시간 이상 | 온라인 수집 시 총 소요시간 **하위 5% 또는 문항당 2초 미만** | 아래 주③ |
| **C6** | 주의점검 문항 실패 | 삽입한 주의점검 문항(instructed response item) 오답 | §1.5 |
| **C7** | 재직기간 논리 오류 | 직무경력 > 연령 − 18, 계급-경력 불일치 등 논리적 불가능 조합 | 논리 검증 |

> 주① **연속 15문항 기준의 근거**: 본 설문은 5개 척도 블록으로 구성되며 최대 블록(WLCS 16문항)의 약 90%에 해당한다. 블록 전체를 동일 응답으로 채운 경우를 포착하되, 특정 척도에 대해 실제로 일관된 태도를 가진 응답을 과잉 제외하지 않는 절충값이다. **수집 후 이 수치를 바꾸지 않는다.**
>
> 주② **C4는 두 지표의 동시 충족(∧)을 요구**한다. 단일 지표만으로 제외하면 정상 응답의 과잉 제거 위험이 크다. 단, 역문항(WLCS 내적 8문항)이 있으므로 역채점 **이전** 원자료에서 산출한다.
>
> 주③ 지류(종이) 설문 병행 시 C5는 온라인 응답에만 적용하며, 이 사실을 논문에 명시한다.

**제외율 상한 사전 규정**: 총 제외율이 **15%를 초과**하면, 단순 제외로 처리하지 않고 **제외 집단과 잔존 집단의 인구통계 분포를 비교(χ²·t)** 하여 체계적 탈락(systematic attrition) 여부를 검정하고 그 결과를 한계 절에 기술한다.

### 1.2 결측치 처리 (Missing Data)

| 결측 수준 | 처리 방식 | 사전 규칙 |
|---|---|---|
| 개인별 결측 **5개 이상**(전체 46문항 기준) | **케이스 제외** (C2) | 수집 전 확정 |
| 개인별 결측 **1~4개** | **FIML**(Full Information Maximum Likelihood) — lavaan `missing = "fiml"` | 기본 전략 |
| 문항별 결측률 **10% 초과 문항** | 결측 패턴 분석 후 해당 문항의 지시문·문구 문제를 4장에 보고, 필요 시 해당 문항 제외 검토 | 사전 규칙 |

- **결측 메커니즘 진단**: Little's MCAR test를 실시하여 결과(χ², df, p)를 보고한다. MCAR이 기각되어도 FIML은 **MAR 가정** 하에서 편향 없는 추정을 제공하므로 FIML을 유지하되, 결측과 관련된 보조변수(auxiliary variables: 연령, 경력, 소속)를 포함한 **saturated correlates 모형**으로 처리한다.
- **평균 대체(mean imputation)·결측 케이스 목록별 삭제(listwise deletion)는 사용하지 않는다.** PROCESS(SPSS/R) 사용 구간에서는 listwise가 강제되므로, **주 분석은 lavaan FIML, PROCESS 결과는 보조·수렴 확인용**으로 위치시킨다(§8.3).

### 1.3 이상치 진단 (Outliers)

| 유형 | 지표 | 기준 | 처리 |
|---|---|---|---|
| **단변량** | 표준화 z | \|z\| > 3.29 (p < .001, 양측) | 제거하지 않고 **표시 후 민감도 분석** |
| **다변량** | Mahalanobis D² | p < .001 (χ², df = 변수 수) | 표시 후 민감도 분석 |
| **영향치** | Cook's D | D > 4/n | 회귀 구간에서 점검 |
| **레버리지** | Centered leverage | > 3(k+1)/n | 회귀 구간에서 점검 |

**처리 원칙(사전 확정)**: 이상치는 **원칙적으로 제거하지 않는다.** 대신 ① 이상치 포함 모형과 ② 이상치 제외 모형을 **모두 추정하여 주요 경로계수의 부호·유의성이 동일한지** 확인하는 **민감도 분석(sensitivity analysis)** 을 실시하고, 결과가 일치하면 포함 모형을 본 분석으로 보고한다. 결과가 달라지는 경우에만 제거를 검토하며, 제거 시 사유·건수·전후 비교를 반드시 게재한다.

> **이유**: 소방공무원처럼 극단적 직무 경험을 가진 표본에서 극단값은 측정 오류가 아니라 **실재하는 현상**일 수 있다. 무비판적 제거는 오히려 '과도한 내적통제' 같은 본 연구의 표적 현상을 잘라내는 결과를 낳는다.

### 1.4 역채점 및 변수 생성

| 처리 | 대상 | 절차 |
|---|---|---|
| **역채점** | WLCS 내적통제 8문항 (원척도 item 1, 2, 3, 4, 7, 11, 14, 15) | ⚠️ **본 연구는 내적·외적을 분리 변수로 사용하므로, Spector(1988)의 '내적 역채점 후 총점 산출' 채점키를 그대로 적용하지 않는다.** 내적통제 8문항은 **정채점(높을수록 내적통제 강함)**, 외적통제 8문항은 **정채점(높을수록 외적통제 강함)** 으로 각각 별도 평균을 산출한다. 이 처리 방식과 원척도 채점키의 차이를 3.3.1절에 **반드시 명시**한다. |
| **문항 배치 역순화** | 무작위 배포본 사용 시 | 원 문항번호(Q8~Q53)로 재정렬 후 분석 |
| **척도 점수** | 각 잠재변수 | 관측변수 분석 시 **문항 평균**(합계 아님) 사용 → 5점 척도 원단위 유지로 해석 용이 |
| **상호작용항** | 조절효과 | **평균중심화(mean-centering) 후 곱항 생성** (§7.4) |

### 1.5 자료 수집 단계에 반드시 포함할 장치 (⚠️ 배포 전 최종 확인)

본 절은 **자료 수집 후에는 되돌릴 수 없는 항목**이다. 설문 배포 전에 반드시 반영할 것.

| 장치 | 내용 | 없으면 불가능해지는 분석 |
|---|---|---|
| **① 마커변수(marker variable) 1~3문항** | 본 모형의 어떤 변수와도 이론적으로 무관한 문항(예: 색상 선호, 계절 선호) | **CFA marker technique·Lindell-Whitney 보정 전면 불가** (§5.2) |
| **② 소속 기관 코드** | 소속 119안전센터 또는 소방서 식별 코드(개인식별 아님) | **ICC(1)/ICC(2)·설계효과·군집강건 표준오차 산출 전면 불가** (§6.4) |
| **③ 주의점검 문항 1~2개** | "이 문항은 '보통이다'를 선택해 주십시오" 형식 | 불성실응답 판정 기준 C6 불가 |
| **④ 응답 소요시간 기록** | 온라인 플랫폼 타임스탬프 | 불성실응답 판정 기준 C5 불가 |
| **⑤ 종속변수 응답형식 분리(권장)** | 안전시민행동을 **5점 빈도형**으로 전환 | 절차적 CMB 통제의 최강 수단 상실 (§5.1, §10.4) |

> **②의 익명성 처리**: "소속 기관 단위 정보만 수집하며 개인 식별에는 사용되지 않습니다"를 명기하여 익명성 안내문과 충돌하지 않도록 한다. 또는 조사자가 배포 시점에 부여하는 센터 코드를 설문지 상단에 사전 인쇄한다.

### 1.6 정규성 점검

| 지표 | 기준 | 위반 시 대응 |
|---|---|---|
| 문항별 왜도(skewness) | \|왜도\| < 2 | 초과 시 해당 문항 분포를 4.2절에 보고 |
| 문항별 첨도(kurtosis) | \|첨도\| < 7 | 초과 시 추정법 전환 검토 |
| 다변량 정규성 | Mardia's multivariate kurtosis | 위반 시 **MLR**(robust ML, Satorra-Bentler 보정) 적용 |

**사전 확정 규칙**: 왜도 \|2\| 또는 첨도 \|7\| 을 초과하는 문항이 **1개라도 있으면** CFA·SEM의 기본 추정법을 **ML → MLR(robust ML)** 로 전환하고, 이 경우 χ² 차이검정은 일반 Δχ²가 아니라 **Satorra-Bentler scaled Δχ²** 를 사용한다. (Curran, West, & Finch, 1996, *Psychological Methods*, 1(1), 16–29. https://doi.org/10.1037/1082-989x.1.1.16 **[검증됨]**)

**천장·바닥효과 사전 점검(특히 안전시민행동)**: 문항 평균 **M > 4.3** 또는 **M < 2.0** 인 문항은 천장·바닥효과 의심 문항으로 별도 표기하고, 해당 문항의 분산·요인부하량을 4.2절에 개별 보고한다. 안전시민행동은 소방 조직에서 규범적으로 극도로 바람직한 행동이므로 천장효과 위험이 가장 높다(§10.4 참조).

| | 소속 기관(센터/소방서) | **군집 수, 군집당 평균 인원**(ICC 산출용) |

### 2.2 대표성 점검

- 소방청 공표 통계(성별·계급·직무 분포)와 본 표본 분포를 **χ² 적합도 검정**으로 비교하여 대표성을 논의한다.
  - ⚠️ 소방청 통계 수치는 본 분석계획 작성 시점에 **미확보**이다. 연구자가 소방청 『소방청 통계연보』 또는 e-나라지표에서 직접 확보하여 4.1절에 인용할 것. **[확인 필요]**
- 표본이 편의표집(convenience sampling)인 경우, 그 사실과 일반화 한계를 5.3절에 명시한다.

### 2.3 무응답 편향(nonresponse bias) 점검

**조기 응답자 vs 후기 응답자 비교(wave analysis)**: 응답 시점 기준 상위 25%와 하위 25% 집단 간 주요 변수 평균을 t-검정으로 비교하고, 유의한 차이가 없으면 무응답 편향이 심각하지 않다고 논증한다. 결과를 4.1절 또는 각주에 보고한다.

## 3. 타당성 검증 (제4장 4.2절)

### 3.0 분석 순서와 표본 분할 전략

| 단계 | 내용 | 표본 |
|---|---|---|
| **예비조사(pilot)** | n ≥ 50 (권장 100) — 문항분석, 초기 EFA, 신뢰도, 천장·바닥효과 점검 | 본조사와 **분리된 표본** |
| **본조사 (1) EFA** | 요인구조 탐색 | 전체 표본 **무작위 절반(split-half)** |
| **본조사 (2) CFA** | 요인구조 확인·경쟁모형 비교 | 나머지 절반 |
| **본조사 (3) 구조모형** | 가설검증 | **전체 표본** |

> **사전 확정 규칙**: 총 N ≥ 500이면 위 split-half 교차타당화(cross-validation)를 실시한다. N < 400이면 split-half의 검정력 손실이 크므로 **전체 표본으로 CFA만 실시**하고, EFA는 예비조사 표본에서 수행한 결과로 대체하며 이 사실을 4.2절에 명시한다. **수집 후 이 규칙을 변경하지 않는다.**
>
> **이유**: 동일 표본에서 EFA로 구조를 찾고 같은 표본으로 CFA를 돌리는 것은 순환논증이며, 측정 전공 심사위원이 반드시 지적하는 지점이다.

### 3.1 탐색적 요인분석 (EFA)

| 항목 | 사전 확정 사양 |
|---|---|
| 적합성 검정 | **KMO ≥ .80**(최소 .70), **Bartlett 구형성 검정 p < .001** |
| 요인추출 | **주축분해(principal axis factoring)** — 주성분분석(PCA)이 아님. 잠재 구인 추정이 목적이므로 PAF가 정당 |
| 요인수 결정 | **평행분석(parallel analysis)** 을 주 기준으로 하고, 고유값 > 1(Kaiser) 및 스크리 도표를 보조로 병기 |
| 회전 | **사각회전(oblique, promax 또는 oblimin)** — 하위차원 간 상관을 전제하므로 직교회전(varimax) 금지 |
| 문항 채택 기준 | 요인부하량 **≥ .40**, 교차부하량(cross-loading) **< .40** 또는 주부하-교차부하 **차이 ≥ .20**, 공통성(communality) **≥ .30** |
| 보고 | 요인부하 행렬(패턴행렬), 요인 간 상관행렬, 설명분산(%), 누적설명분산 |

**사전 확정된 문항 제거 규칙**: 위 기준 위반 문항은 **한 번에 하나씩** 제거하고 매번 재추정한다. 제거한 문항은 4.2절에 **문항번호·부하량·제거 사유**를 표로 게재한다. 사후에 조용히 빼는 것이 가장 의심받는다.

**⚠️ 반드시 한 번에 투입할 EFA (교차부하 사전 탐지)**: 실책관리풍토 8문항(Q34~Q41)과 피드백추구행동 10문항(Q24~Q33)은 **어휘장이 중복**되므로(§10.3 risk 5), 이 18문항을 한 EFA에 동시 투입하여 교차부하 > .40 문항을 사전에 식별한다. 본조사 이후에 발견하면 손쓸 방법이 없다.

### 3.2 확인적 요인분석 (CFA) — 적합도 지수 기준

#### 3.2.1 적합도 판정 기준 (사전 확정)

| 지수 | 수용 가능(acceptable) | 양호(good) | 비고 |
|---|---|---|---|
| **χ²** | — | — | 유의성만으로 판단하지 않음(N 민감). χ² 값·df·p를 보고 |
| **χ²/df (Normed χ²)** | ≤ 3.0 | ≤ 2.0 | |
| **CFI** | ≥ .90 | ≥ .95 | |
| **TLI (NNFI)** | ≥ .90 | ≥ .95 | |
| **RMSEA** | ≤ .08 | ≤ .06 | **90% 신뢰구간 병기 필수** |
| **SRMR** | ≤ .08 | ≤ .05 | |
| **AIC / BIC** | — | 낮을수록 우수 | **경쟁모형 비교 전용** |

출처: Hu, L., & Bentler, P. M. (1999). Cutoff criteria for fit indexes in covariance structure analysis. *Structural Equation Modeling*, 6(1), 1–55. https://doi.org/10.1080/10705519909540118 **[검증됨]**

> **보고 원칙**: 단일 지수로 판정하지 않고 **χ²/df, CFI, TLI, RMSEA[90% CI], SRMR 5종을 항상 함께** 보고한다. 일부 지수만 골라 제시하면 즉시 의심받는다.

#### 3.2.2 경쟁모형 비교 — ⚠️ 본 연구의 생사가 걸린 절차

본 연구는 세 개의 척도에서 **원척도와 다른 요인구조를 전제**하고 있다. 각각에 대해 **경쟁모형 CFA를 반드시 실시**하고 비교표를 게재한다. 이것 없이는 박사 심사 방어가 불가능하다.

**(A) 통제위치(WLCS) — 4개 경쟁모형** (§10.1 risk 1·2 대응)

| 모형 | 구조 | 의미 |
|---|---|---|
| **M1** | 1요인 (16문항, 내적 역채점 후 단일 externality) | **원저자 Spector(1988)의 공식 입장** |
| **M2** | **2요인 (내적 8 / 외적 8)** | **본 연구가 전제하는 구조** — Macan et al.(1996) 지지 |
| **M3** | 1요인 + **진술방향 방법요인**(wording direction method factor) | 2요인이 실은 방법효과인지 검정 |
| **M4** | 3요인 (External / Internal-1 / Internal-2) | Oliver, Jose & Brough(2006)가 지지한 구조 |

**사전 확정 판정 규칙**
- **M2가 M1·M3·M4 대비 최우수 적합**(CFI/TLI 최대, RMSEA/SRMR 최소, AIC/BIC 최소) → 2요인 분리 채택. 정당화 완료.
- **M3 ≥ M2** (M3가 동등하거나 우수) → **2요인 해석을 철회**하고 16문항 총점 사용으로 회귀. 이 경우 연구모형을 '통제위치(단일차원) → FSB'로 수정하고 가설 H1-1~H1-4를 재구성한다.
- **M4 > M2** → 3요인을 채택하되, Internal-1을 **'노력–성과 신념'**, Internal-2를 **'조직 내 영향력 행사 신념'** 으로 명명하여 **이론적 정교화(기여)** 로 전환한다.
- **추가 필수 보고**: 내적·외적 하위척도 간 **상관계수 r**. `r ≤ -.70`이면 사실상 단일 연속선이라는 반증이므로 2요인 주장을 철회한다. `-.30 ~ -.50` 수준이면 별개 차원 주장이 유지된다(국내 참조점: 장영순·이종구(2010) r = -.42).

**(B) 안전시민행동(SCB) — 4개 경쟁모형** (§10.4 risk 3·4 대응)

| 모형 | 구조 | 비고 |
|---|---|---|
| **S1** | 1요인 (12문항) | **원저자 Hofmann et al.(2003)이 실제로 사용한 방식** (하위척도 간 평균 r = .71~.78로 높아 전체 합산) |
| **S2** | 6요인 1차 모형 (차원당 2문항) | ⚠️ **거의 확실히 실패한다** — 2지표 요인은 Heywood case·수렴 실패·요인상관 .9대가 빈발 |
| **S3** | **2차 요인 2개** — 친화지향(affiliative: 시민의식·지원·자원참여·보고) / 도전지향(challenging: 발언·변화주도) | **Curcuruto, Conchie & Griffin(2019)** N=1,011 4개국에서 최적 적합 |
| **S4** | 1요인 + 6 parcel (차원별 2문항 평균을 parcel로) | 문항 추가 불가 시의 차선책 (df = 9, 안정적 추정) |

**사전 확정 판정 규칙**
- **S3(2차 요인 2개)를 1순위 채택 대상으로 한다.** 이는 통계적 해결책일 뿐 아니라 **본 연구의 핵심 논리에 직접 봉사**한다:
  - '과도한 내적통제 → 단독행동·과잉책임'은 곧 **"내적통제가 도전지향 SCB(개인이 나서는 행동)는 높이나 친화지향 SCB(팀과 함께 가는 행동)는 높이지 못하거나 낮춘다"** 는 가설로 번역된다.
  - '외적통제 + 부정적 피드백추구 → 팀과 함께 움직임'은 **친화지향 SCB 상승**으로 예측된다.
  - ⚠️ **종속변수를 단일 총점으로 뭉개면 이 상반된 두 효과가 상쇄되어 아무 결과도 나오지 않을 위험이 있다.** 2차 요인 분리는 본 연구에서 선택이 아니라 사실상 필수다.
- **S2(6요인 1차)는 절대 단독으로 보고하지 않는다.** 수렴하더라도 요인상관 .9대·Heywood case가 나와 심사에서 그대로 무너진다. 비교 목적으로만 추정하고 실패 사실 자체를 투명하게 보고한다.
- 문항을 차원당 3문항(총 18문항)으로 확대했다면 S2·S3 모두 온전한 검정이 가능해진다(§10.4 risk 4 권고).

**(C) 실책관리풍토(EMC) — 3개 경쟁모형** (§10.3 risk 2·8 대응)

| 모형 | 구조 | 비고 |
|---|---|---|
| **E1** | 1요인 (8문항) | 현재 전제. Porto et al.(2020) 브라질판 17문항이 1요인 지지(α=.94) |
| **E2** | **2요인** — 실책관리(학습·분석·소통: Q35·Q38·Q39·Q40) / **실책회피 역방향**(비난·은폐·처벌: Q34·Q36·Q37·Q41) | ⚠️ 원저 van Dyck et al.(2005)은 EMC/EAC 두 요인이 **독립**이며 상관 r = -.20(p<.10, 비유의)임을 명시 |
| **E3** | 2차 요인 1개 (4 facet) | 원저 구조와 정합 |

**사전 확정 판정 규칙**
- **E1이 지지되면** 단일 지표 평균 사용. 3.3절에 Porto et al.(2020)을 근거로 인용.
- **E2가 우수하면** 조절변수를 **2개 하위차원으로 분리**하여 각각 조절변수로 투입한다. 이는 약점이 아니라 정교화로 읽히며, 소방 조직에서는 '실책회피풍토'가 이론적으로 더 강한 조절자일 가능성이 있어 예상외 발견의 여지를 준다.
- ⚠️ **α가 .90 이상 나와도 단일차원성의 증거가 되지 못한다.** α는 차원성 지표가 아니다. EFA(평행분석) + CFA 적합도 + AVE를 반드시 병기한다.

**(D) 피드백추구행동(FSB) — 2개 경쟁모형**

| 모형 | 구조 |
|---|---|
| **F1** | 1요인 (10문항) |
| **F2** | **2요인 (긍정 5 / 부정 5)** — 본 연구가 전제하는 구조 |

- ⚠️ **긍정 FSB가 2요인으로 쪼개질 가능성이 높다.** 김어림·한태영(2018)에서도 긍정 피드백추구행동이 2개 요인으로 분리되었고, 허창구 등(2021)의 긍정 FSB α는 **.69**로 경계선이었다. 원인은 Q26·Q28이 행동이 아니라 **동기(인정욕구·인상관리)** 를 측정하기 때문이다(§10.2 risk 3).
- 긍정 FSB가 2요인으로 분리되면 **'긍정적 피드백추구' 대신 '자기확증형 피드백추구'와 '인정추구' 로 명명 분리**를 검토하되, 사후 명명(post-hoc labeling)임을 명시한다.

**(E) 전체 측정모형 (Full Measurement Model)**

최종 채택된 요인구조를 모두 결합한 **전체 측정모형**(내적통제 / 외적통제 / 긍정FSB / 부정FSB / 실책관리풍토 / SCB)을 추정하여 적합도를 보고한다. 이것이 §3.4 판별타당도와 §5 공통방법편향 검증의 기준모형(baseline)이 된다.

### 3.3 수렴타당도 (Convergent Validity)

| 지표 | 기준 | 산출 |
|---|---|---|
| **표준화 요인부하량(λ)** | ≥ .50 (권장 ≥ .70), **모두 p < .001 유의** | CFA |
| **평균분산추출 AVE** | **≥ .50** | AVE = Σλ² / (Σλ² + Σθ) |
| **개념신뢰도 CR (Composite Reliability)** | **≥ .70** | CR = (Σλ)² / [(Σλ)² + Σθ] |

출처: Fornell, C., & Larcker, D. F. (1981). Evaluating structural equation models with unobservable variables and measurement error. *Journal of Marketing Research*, 18(1), 39–50. https://doi.org/10.2307/3151312 **[검증됨]**

**사전 확정 대응 규칙**
- **AVE가 .50 미만이나 CR ≥ .70인 경우**: 수렴타당도가 여전히 수용 가능하다는 논리를 사용할 수 있으나, 반드시 그 사실을 명시하고 근거를 제시한다.
- **특정 문항의 λ < .40**: 제거를 검토하되, 제거 전후의 AVE·CR·모형적합도 비교표를 게재한다. 특히 다음 문항은 **사전 지정 중점 관찰 문항**이다.

| 척도 | 중점 관찰 문항 | 사전 지정 사유 |
|---|---|---|
| WLCS | **item 4** ("상사의 결정이 불만이면 무언가 조치를 취해야 한다") | 통제신념이 아닌 **규범적·당위적 진술**. 준군사조직(계급제)에서는 조직문화 순응도·사회적 바람직성을 측정하게 됨. **수정보다 제거를 우선 검토** (발언행동·심리적 안전감과 개념 중복 위험) |
| WLCS | **item 15** ("대부분의 직원은 생각보다 상사에게 더 많은 영향력을 가진다") | 소방 지휘체계에서 응답 왜곡이 쉬움 |
| WLCS | **item 6, 12, 16, 5, 8, 10** ('돈 버는 것' 소재 4문항 포함) | 소방공무원은 호봉제로 급여 법정 고정 → 분산 소실 또는 무작위 응답 위험 (§10.1 risk 3) |
| FSB | **Q26, Q28** | 행동이 아니라 **동기**(self-enhancement / impression management)를 측정 |
| FSB | **Q27, Q32** | **이중 바렐(double-barreled)** — 상황판단 + 행동 결합 |
| FSB | **Q31** | 독립변수(내적통제)와 **개념 중첩** — '실수 귀인 → 자기 책임' 전제 |
| EMC | **Q40** | 매개변수 Q31과 '실수 + 피드백' 어휘장 중복 |
| EMC | **Q34, Q36, Q41** | **이중 바렐** — 두 명제 결합 |
| SCB | **Q50** | 원문의 **'비의무(nonmandatory)' 한정어가 소실** → 역할외 시민행동이 아닌 역할내 순응을 측정 |

### 3.4 판별타당도 (Discriminant Validity) — ⚠️ 본 연구의 최대 취약점 방어

| 기준 | 판정 규칙 | 비고 |
|---|---|---|
| **Fornell-Larcker** | 각 구인의 **√AVE > 해당 구인과 다른 모든 구인의 상관계수** | Fornell & Larcker (1981) **[검증됨]** |
| **AVE vs 상관제곱** | **AVE > 요인간 상관²** | 위와 동치 |
| **HTMT** (Heterotrait-Monotrait ratio) | **HTMT < .85** (엄격) 또는 **< .90** (보수적 상한) | Henseler, J., Ringle, C. M., & Sarstedt, M. (2015). *Journal of the Academy of Marketing Science*, 43(1), 115–135. https://doi.org/10.1007/s11747-014-0403-8 **[검증됨]** |
| **χ² 차이검정** | 두 요인 간 상관을 1로 제약한 모형 vs 자유추정 모형의 **Δχ²(df=1) 유의** | 보조 기준 |

**⚠️ 반드시 별도 표로 게재해야 할 판별타당도 쌍 (사전 지정)**

| 쌍 | 위험 | 왜 치명적인가 |
|---|---|---|
| **내적통제 ↔ 외적통제** | 단일 연속선 의혹 | 2요인 분리 설계의 정당성 자체 |
| **내적통제 ↔ 부정적 FSB** | 문항 수준 개념 중첩 (Q31의 '실수 귀인·자책') | 본 논문의 학술적 기여가 '내적통제 → 부정적 FSB'의 역설적 경로인데, 두 변수 문항이 겹치면 **매개효과가 측정 인공물(measurement artifact)** 이라는 치명적 지적을 받는다 |
| **부정적 FSB ↔ 실책관리풍토** | 어휘장 중복 (Q31 ↔ Q40, Q38) | 조절변수-매개변수 중복 시 **상호작용항이 인위적으로 팽창**하여 유의한 조절효과가 구성개념 중복의 산물이 된다 |
| **실책관리풍토 ↔ SCB** | 안전 관련 어휘 공유 | 조절변수-종속변수 중복 |
| **긍정적 FSB ↔ 부정적 FSB** | 동일 척도 내 하위차원 | 매개변수 분리 설계의 정당성 |

> **선제 방어 원칙**: 위 5개 쌍의 √AVE·상관·HTMT를 **하나의 표로 미리 준비**하여 4.2절에 게재한다. 먼저 제시하면 방어가 되고, 지적받은 뒤 제시하면 변명이 된다.

## 4. 신뢰도 검증 (제4장 4.2절)

### 4.1 보고 지표 (3종 병기)

| 지표 | 기준 | 사용 이유 |
|---|---|---|
| **Cronbach's α** | ≥ .70 (탐색적 연구 ≥ .60) | 관례적 필수 보고 |
| **McDonald's ω** | ≥ .70 | **α는 타우등가성(tau-equivalence) 가정 위반 시 신뢰도를 과소추정**하므로, ω가 더 방어적이다. `semTools::reliability()` 로 산출 |
| **복합신뢰도 CR** | ≥ .70 | CFA 기반 잠재변수 신뢰도. §3.3과 동일 산출 |
| 문항-총점 상관 (corrected item-total correlation) | ≥ .30 | 문항 제거 판단용 |
| 문항 제거 시 α (α if item deleted) | — | 문항 제거 판단 보조 |

### 4.2 ⚠️ 선행연구 신뢰도 인용 시 반드시 지킬 원칙

박사 심사에서 **가장 쉽게 발견되고 가장 자주 지적되는 실수**가 신뢰도 수치 불일치다.

| 척도 | 절대 이렇게 쓰지 말 것 | 반드시 이렇게 쓸 것 |
|---|---|---|
| **WLCS** | "선행연구에서 α = .83으로 보고되었다" | "**전체 16문항 총점 기준** α = .83(Spector, 1988; 미국 37개 연구 누적 N = 5,477)이며, **내적·외적 하위척도로 분리 시 통상 내적 .70~.78, 외적 .75~.82** 수준으로 보고된다." — **문항 수 기준을 명시**한다. .83은 16문항 총점 기준이며 8문항으로 쪼개면 Spearman-Brown 원리상 α가 **구조적으로 하락**한다. 여기에 5점 축소와 맥락화 수정이 겹치면 추가 하락이 예상된다. |
| **SCB** | "Hofmann et al.(2003)에서 α = .96" | "**27문항 전체 합산·팀장 평정 기준** α = .96이며, **본 연구는 차원당 2문항 자기보고**이므로 직접 비교할 수 없다. 참고치로 Curcuruto et al.(2019) 4개국 자기보고 27문항 α = .93~.97, 차원별 α는 Civic Virtue .74~.82 ~ Stewardship .85~.96." |
| **EMC** | "van Dyck et al.(2005) α = .92" | "**원 17문항 기준** α = .92이며, **본 연구는 재구성 8문항**이다. 문헌상 **공식 8문항 축약본은 존재하지 않는다**(확인된 축약 선례는 원문항 #2·#4·#5·#7·#8의 5문항판, α = .79)." |
| **FSB** | "Ashford & Tsui(1991) 척도의 α" | 원전 α값은 **공개 소스에서 확보 불가**(AOM 유료·403). 국내 참조치: 김어림·한태영(2018) 긍정 .76 / 부정 .77, 허창구 등(2021) 긍정 **.69** / 부정 .79, 이정희·탁진국(2022) 부정 .86, 권태희·정은경(2025) 긍정 .775 / 부정 .788 |

### 4.3 신뢰도 미달 시 사전 확정 대응

| 상황 | 대응 |
|---|---|
| **α < .70, ≥ .60** | 문항-총점 상관이 낮은 문항(특히 §3.3의 중점 관찰 문항)을 제거한 축소판 사용 검토. **제거 근거와 제거 전후 α 비교를 투명하게 게재.** 동시에 ω·CR을 병기하여 α의 과소추정 가능성을 논의 |
| **α < .60** | 해당 하위척도를 **단독 변수로 사용하지 않는다.** ① 상위 요인으로 통합하거나 ② 해당 가설을 탐색적 분석으로 격하하고 한계 절에 명시 |
| **차원당 2문항의 α** | k=2일 때 α는 문항 간 상관의 Spearman-Brown 변환에 불과하다(r = .50 → α = .67). **α ≥ .70을 얻으려면 문항 간 r ≥ .54가 필요**하다. SCB 6차원별 α가 .6대로 나올 것을 사전에 예상하고, **차원별 α 대신 상위 2요인(친화/도전)의 α·ω·CR을 주 지표로 보고**할 것 |

> **절대 하지 말 것**: 사후에 조용히 문항을 빼는 것. 제거 전후 비교표가 없으면 가장 의심받는다.

## 5. 공통방법편향 검증 (Common Method Bias, CMB)

> **왜 이 절이 본 연구에서 특히 중요한가**: 독립변수(통제위치)·매개변수(피드백추구)·조절변수(실책관리풍토)·종속변수(안전시민행동)가 **모두 동일 응답자·동일 시점·동일 5점 동의형 자기보고**이다. 더욱이 세 척도 모두 **원전은 다중원천(multi-source) 설계**였다.
> - Ashford & Tsui(1991) FSB = **상사·부하·동료 3개 constituency 타인평정**
> - Hofmann et al.(2003) SCB = **팀장 평정**(자기보고로 측정된 것은 '역할정의'였지 '행동'이 아님)
> - van Dyck et al.(2005) EMC = **조직 수준 집계** (rWG(J) = .92)
>
> 즉 **원전 설계의 핵심 장치를 모두 제거해 놓고 원전을 인용하는 구조**이므로, 심사에서 지적되면 답변이 궁색해진다. 절차적·통계적 통제를 **선제적으로** 기술해야 한다.

### 5.1 절차적 통제 (Procedural Remedies) — 설문 배포 전에만 가능

근거: Podsakoff, P. M., MacKenzie, S. B., Lee, J.-Y., & Podsakoff, N. P. (2003). Common method biases in behavioral research. *Journal of Applied Psychology*, 88(5), 879–903. https://doi.org/10.1037/0021-9010.88.5.879 **[검증됨]**

| 통제 | 실행 내용 | 상태 |
|---|---|---|
| **① 응답형식 분리 (scale-format separation)** | **WLCS는 원척도대로 6점 유지**(중간점 부재가 개발자의 설계 의도), 매개·조절은 5점 동의형, **종속변수(SCB)는 5점 빈도형**('전혀 하지 않는다 ~ 매우 자주 한다') | ⚠️ **미반영 — 배포 전 결정 필요** |
| **② 심리적 분리** | 섹션 간 지시문 삽입, 변수 간 문항 블록 물리적 분리 | 배포본 확인 필요 |
| **③ 문항 순서 무작위화** | 이미 준비된 `survey/02_설문지_배포본_무작위.md` 를 **실제로 사용** | 준비됨 |
| **④ 익명성·정답 없음 보장** | IV 섹션과 DV 섹션 앞에 **반복 배치** | 확인 필요 |
| **⑤ 마커변수 삽입** | 본 모형과 이론적으로 무관한 1~3문항 | ⚠️ **미반영 — 배포 후 불가능** |
| **⑥ 시차 설계(최선)** | T1: IV·조절 / T2: M / T3: DV (2~4주 간격). 최소 2시점 | 가능하면 도입 |
| **⑦ 다중원천(최강)** | SCB를 팀장 또는 동료 평정으로 하위표본이라도 수집 | 가능하면 도입 |

> **①의 이중 방어 논리(3.3절에 한 문단으로 반드시 명시할 것)**: "WLCS만 6점을 유지하는 것은 ⓐ 원척도 충실성(개발자가 중간점 부재를 설계 의도로 채택) 확보와 ⓑ **Podsakoff et al.(2003)이 권고한 방법론적 분리(methodological separation)를 통한 공통방법편의 통제**를 동시에 달성한다." 이 한 문단이 '척도마다 형식이 제각각'이라는 약점을 '설계 단계에서 CMV를 통제했다'는 강점으로 뒤집는다.
>
> ⚠️ 단, `docs/_확정사항.md`는 **전 척도 5점 통일**을 교수님 검토 완료 항목으로 확정하고 있다. 변경하려면 **지도교수 재승인이 필요**하다. 5점 통일을 유지할 경우 반드시 다음 4가지를 갖출 것: ⓐ 변경 사실과 사유를 3.3절에 명시, ⓑ 예비조사에서 5점판·6점판의 α·요인구조·평균 비교로 등가성 근거 제시, ⓒ Spector 규준(총점 16~96) 비교를 하지 않는다고 선언, ⓓ 5.3절 한계에 기술.

### 5.2 통계적 통제 (Statistical Remedies) — 3단계 위계 검증

**모두 실시하고 4.2절에 순서대로 보고한다.** Harman 단일요인만 보고하는 것은 최소 기준조차 못 되며, 오히려 "이것만 했나"라는 지적을 부른다.

#### 5.2.1 [1단계] Harman 단일요인 검정 (Harman's single-factor test)

| 방식 | 판정 기준 |
|---|---|
| **EFA 방식** | 전 문항을 회전 없이 요인분석 → **제1요인 설명분산 < 50%** |
| **CFA 방식(권장)** | 전 문항을 **단일 요인**에 적재한 모형을 추정 → **적합도가 수용 기준에 크게 미달**해야 함 |

> **활용 가능한 선례**: Curcuruto, Conchie & Griffin(2019)은 4개 표본 모두에서 SCB 단일요인 모형이 **CFI .679~.800, RMSEA .132~.205** 로 기각됨을 보고했다. 본 연구에서도 동일 수치대가 나오면 이를 인용하여 "선행연구와 동일한 패턴"으로 기술할 수 있다.
>
> ⚠️ **한계 명시 의무**: Harman 검정은 **검정력이 낮아 CMB의 부재를 입증하지 못한다.** "Harman 검정 결과 문제없었다"로 끝내면 안 된다. 반드시 2·3단계를 병행하고, Harman은 최소 요건 충족으로만 위치시킨다.

#### 5.2.2 [2단계] 마커변수 기법 (Marker Variable Technique)

| 방식 | 절차 | 출처 |
|---|---|---|
| **Lindell-Whitney 상관 보정** | 이론적 무관 마커변수와 실질변수 간 **최소 양의 상관(r_M)** 을 방법분산 추정치로 간주하고, 전 상관계수를 부분상관으로 보정 → 보정 후에도 유의한 상관이 유지되는지 확인 | Lindell, M. K., & Whitney, D. J. (2001). *Journal of Applied Psychology*, 86(1), 114–121. https://doi.org/10.1037/0021-9010.86.1.114 **[검증됨]** |
| **CFA marker technique (권장)** | Baseline(CFA) → Method-C(마커요인 적재 동일 제약) → Method-U(자유) → Method-R(구조계수 제약) 의 **4모형 순차 비교**. 각 단계 Δχ² 검정으로 방법효과의 존재·균질성·구조계수 영향을 분리 판정 | Williams, L. J., Hartman, N., & Cavazotte, F. (2010). *Organizational Research Methods*, 13(3), 477–514. https://doi.org/10.1177/1094428110366036 **[검증됨]** |

⚠️ **마커변수 문항이 설문에 없으면 이 단계는 전면 불가능하다.** §1.5 ①을 배포 전에 반드시 반영할 것. 배포 후에는 마지막 기회가 사라진다.

#### 5.2.3 [3단계] 비측정 잠재방법요인 (ULMC, Unmeasured Latent Method Construct)

- **절차**: 전체 측정모형에 모든 관측변수가 적재되는 **잠재방법요인 1개**를 추가한 모형을 추정.
- **판정**: ① 방법요인 추가 후 **적합도 개선이 미미**(ΔCFI < .01)하고, ② **실질요인의 표준화 요인부하량이 유의성을 유지**하며, ③ 방법요인이 설명하는 분산이 실질요인 설명분산보다 현저히 작으면 CMB가 심각하지 않다고 판단.
- **주의**: ULMC는 방법요인이 식별되지 않아 수렴 실패가 잦다. 실패 시 그 사실을 보고하고 마커변수 결과를 주 근거로 삼는다.

### 5.3 조절효과에 대한 CMB 방어 논리 (본 연구의 결정적 방패)

> **공통방법분산은 상호작용(조절) 효과를 인위적으로 생성하지 않으며, 오히려 축소(deflate)시키는 방향으로 작용한다.** 따라서 본 연구의 조절효과(H4·H5 계열)가 유의하게 나타나면 그것은 **보수적 검정을 통과한 결과**이며 CMB로 설명되지 않는다.
>
> 근거: Siemsen, E., Roth, A., & Oliva, R. (2010). Common method bias in regression models with linear, quadratic, and interaction effects. *Organizational Research Methods*, 13(3), 456–476. https://doi.org/10.1177/1094428109351241 **[검증됨 — 단 Crossref 저자 표기가 "Oliveira"로 등재되어 있어, 참고문헌 확정 전 출판본 원문에서 제3저자 표기(Oliva)를 재확인할 것]**

**이 논리는 본 연구에 특히 유리하다.** 본 연구의 핵심 주장은 주효과가 아니라 **조건부 효과(조절된 매개)** 에 있기 때문이다. 5.3절 한계 논의에 반드시 포함할 것.

## 6. 기술통계 · 상관분석 · 사전 진단 (제4장 4.2절)

### 6.1 기술통계

변수별 **M, SD, 최소, 최대, 왜도, 첨도**를 표로 제시한다. 문항 수준과 척도 수준을 모두 보고하되, 척도 수준 표를 본문에, 문항 수준 표를 부록에 배치한다.

### 6.2 상관분석

- **Pearson 적률상관행렬**을 제시하며, 대각선에 **√AVE 또는 Cronbach's α를 병기**한다(판별타당도 동시 제시).
- **반드시 함께 보고할 사전 지정 상관**

| 상관 | 보고 이유 |
|---|---|
| **내적통제 ↔ 외적통제** | 2요인 분리 설계의 정당성. r ≤ -.70이면 단일 연속선 반증 (§3.2.2 A) |
| **직무경력 ↔ 긍정/부정 FSB** | Anseel et al.(2015) 메타분석에서 직무재직기간 **ρ = -.15**(k=13, N=3,089), 조직재직기간 **ρ = -.19**(k=11), 연령 **ρ = -.13**(k=13)으로 **모두 부적**. 본 표본에서도 재현되는지 사전 확인 필요 (§7.6 교락 문제) |
| **실책관리풍토 ↔ 부정적 FSB** | 조절변수-매개변수 중복 점검 |
| **통제변수(성별·연령·직무) ↔ 전 변수** | 통제변수 투입 정당화 |

### 6.3 다중공선성 진단 (VIF)

| 지표 | 기준 | 대응 |
|---|---|---|
| **VIF** | < 5 (엄격) 또는 < 10 (보수적 상한) | **기준값을 논문에 명시**하고 일관되게 적용 |
| **공차(Tolerance)** | > .20 | |
| **조건지수(Condition Index)** | < 30 | 보조 |

**⚠️ 억제효과(suppressor effect) 사전 대응 규칙**

내적통제와 외적통제를 동시 투입하면 통상 r = -.30 ~ -.50으로 상관되며, 여기에 매개변수 2개·조절변수 2개·상호작용항이 더해지면 억제효과가 발생하기 쉽다.

> **사전 확정 규칙**: **단순상관의 부호와 회귀·SEM 계수의 부호가 서로 다른 변수가 하나라도 발견되면**, 이를 억제효과 가능성으로 명시적으로 검토·기술하고, 해당 계수를 이론적 발견으로 해석하기 전에 ① 변수 투입 순서를 바꾼 위계적 분석 결과, ② 해당 변수를 단독 투입한 모형의 계수를 함께 제시한다.
>
> **왜 치명적인가**: 억제효과로 인해 단순상관에서 양(+)이던 내적통제 계수가 회귀에서 음(-)으로 뒤집혔을 때, 이를 "과도한 내적통제의 해로움을 입증했다"고 해석하면 **통계적 인공물을 이론으로 착각한 것**이 되어 정면 반박당한다. **먼저 언급하면 방어가 되고, 언급하지 않으면 공격이 된다.**

### 6.4 군집효과(비독립성) 점검 — ⚠️ 프로젝트 최대 취약 문장의 보강

> 현재 `docs/_확정사항.md`는 조절변수를 '**지각된** 실책관리풍토'(psychological climate)로 조작적 정의하고, "집단 수준 집계 및 **ICC(1)/ICC(2)/rwg 산출이 요구되지 않는다**"고 단정한다.
>
> **psychological climate 재정의 자체는 정당하다**(국내외 선례: Yim & Park, 2025, *IJEVG*, 25(2), 465–492). 그러나 **"요구되지 않는다"는 단정 문장이 현 프로젝트 전체에서 가장 공격받기 쉬운 한 줄**이다.
>
> **집계(aggregation)가 불필요한 것과 잔차 비독립성(non-independence)이 없는 것은 전혀 다른 문제**다. 소방 표본은 소방서 → 119안전센터 → 교대팀으로 자연적으로 군집되어 있고, 같은 센터 대원은 실제로 같은 풍토를 공유한다. 비독립성을 방치하면 **표준오차가 과소추정되어 조절효과의 p값이 부풀려진다.** 심사위원이 "ICC가 얼마인가"라고 물었을 때 "산출하지 않았습니다"는 치명적이다. Smith et al.(2019)이 동일한 소방 표본(N=994)에서 선형혼합모형을 쓴 것이 반례로 제시될 수 있다.

**사전 확정 3단계 규칙 (방어를 '산출 불필요'에서 '산출했고 문제없음을 확인했다'로 전환)**

| 단계 | 내용 |
|---|---|
| **① 문장 수정** | `_확정사항.md`의 해당 문장에 다음을 **추가**한다: "단, 표집 구조상 응답의 비독립성 가능성을 점검하기 위해 **ICC(1)을 보고하고 필요 시 군집-강건 표준오차를 적용**한다." |
| **② 설문 수정(가장 시급)** | 인구통계에 **소속 119안전센터(또는 소방서) 식별 문항 추가** (§1.5 ②). 이대로 수집하면 ICC를 계산할 **데이터 자체가 존재하지 않아 사후 반박이 원천 불가능**해진다 |
| **③ 분석 규칙 사전 확정** | 아래 표 |

| 진단 결과 | 사전 확정 대응 |
|---|---|
| **ICC(1) < .05 이고 설계효과 DEFF < 2** | 단일수준 OLS/SEM/PROCESS 유지. **ICC 값을 각주에 보고** |
| **ICC(1) ≥ .05 또는 DEFF ≥ 2** | **군집-강건 표준오차**(cluster-robust SE, 군집 = 안전센터) 적용. lavaan `cluster = "center_id"` 옵션. 또는 소방서 더미 통제 |
| **군집 수 ≥ 30** | **다층모형(MLM)** 검토 |

- 설계효과 산출식: **DEFF = 1 + (평균 군집크기 − 1) × ICC**
- ⚠️ **이 규칙을 자료수집 전에 논문에 명시**해 두면 사후 정당화라는 의심을 받지 않는다.

## 7. 가설검증 (제4장 4.3절)

### 7.0 검증 전략 개요 — 2트랙 병행

| 트랙 | 도구 | 역할 |
|---|---|---|
| **주 분석 (Primary)** | **R lavaan** — 잠재변수 SEM, FIML, 부트스트랩 | 측정오차 보정, 결측 FIML 처리, 다집단 SEM 가능. **논문 본문 결과표의 기준** |
| **보조 분석 (Convergent)** | **PROCESS (R `processR` / SPSS macro)** — 관측변수 회귀 기반 | 국내 심사 관행상 익숙한 산출물. 조건부 간접효과·Johnson-Neyman 도표. **주 분석과 결과가 수렴함을 보이는 용도** |

> **두 결과가 불일치할 경우**: lavaan 결과를 채택하고, 불일치의 원인(측정오차 보정 유무, 결측 처리 방식 차이)을 각주에 설명한다. 유리한 쪽을 골라 보고하지 않는다.

### 7.1 [1단계] 측정모형 검증 (Measurement Model)

§3의 전체 측정모형 CFA 적합도가 수용 기준(§3.2.1)을 충족해야만 구조모형으로 진행한다. **미충족 시 수정지수(MI)에 따른 무분별한 모형 수정을 금지**하고, 수정하는 경우 ① 이론적 근거가 있는 오차 공분산만 ② 최대 2개까지 ③ 수정 내역과 사유를 모두 보고한다.

### 7.2 [2단계] 구조모형 및 직접효과 (H1·H2 계열)

| 가설 | 경로 | 예측 | 검정 |
|---|---|---|---|
| **H1-1** | 내적통제 → 긍정적 FSB | **정(+)** | SEM 직접경로 |
| **H1-2** | 내적통제 → 부정적 FSB | **부(−)** | SEM 직접경로 |
| **H1-3** | 외적통제 → 부정적 FSB | **정(+)** | SEM 직접경로 |
| **H1-4** | 외적통제 → 긍정적 FSB | **무관 또는 H1-1보다 약함** | SEM + 경로계수 크기 비교 |
| **H2-1** | 긍정적 FSB → SCB | 정(+), 제한적 | SEM 직접경로 |
| **H2-2** | 부정적 FSB → SCB | **정(+), H2-1보다 큼** | 등가제약 모형 대 비제약 모형 **Δχ²(df=1)** |
| **H2-3** (보조·탐색) | 부정적 FSB → SCB 관계가 **발언·변화주도·지원** 차원에서 특히 강함 | 차원별 차등 | 차원별 경로계수 비교, Steiger's Z |

**필수 부가 분석**
- **H1-2 ↔ H1-3 경로계수 차이 검정**: 두 경로에 동등 제약을 가한 모형과 자유추정 모형의 **Δχ²(df=1)** 로 검정하여, 내적·외적이 단일 연속선의 양극이 아니라 **서로 다른 기제로 작동**함을 통계적으로 입증한다.
- **2×2 패턴 검정**: H1-1~H1-4가 예측한 패턴(내적→긍정 강, 내적→부정 약/부, 외적→부정 강, 외적→긍정 약)이 관찰되면, 이 패턴 자체가 **2요인 구조의 법칙정립적(nomological) 증거**가 된다. 단일 요인 모형으로는 이 패턴을 설명할 수 없다.

**통제변수**: 성별, 연령, 담당 직무(화재진압/구급), 근무형태, 계급을 모든 모형에 투입한다. (직무경력은 조절변수이므로 통제변수와 조절변수 역할이 중복되지 않도록 §7.6에서 별도 처리)

### 7.3 [3단계] 매개효과 검증 — 부트스트래핑 5,000회 (H3 계열)

| 가설 | 간접효과 경로 | 예측 |
|---|---|---|
| **H3-1** | 내적통제 → **부정적 FSB** → SCB | **부(−)적 간접효과** |
| **H3-2** | 외적통제 → **부정적 FSB** → SCB | **정(+)적 간접효과** — 본 연구 반론의 중심 |
| **H3-3** | 긍정적 FSB 매개 < 부정적 FSB 매개 | 경쟁 매개 대비(contrast) |

**사전 확정 분석 사양**

| 항목 | 사양 |
|---|---|
| 모형 구조 | **병렬다중매개(parallel multiple mediation)** — 긍정·부정 FSB를 **동시 투입**하여 각각의 고유(unique) 간접효과 추정 |
| 독립변수 | 내적통제·외적통제를 **동시 투입**하여 각각의 고유 효과 추정 |
| 부트스트랩 | **5,000회** (재표집), **편향수정 백분위 신뢰구간(bias-corrected percentile CI) 95%** |
| 유의 판정 | **95% CI가 0을 포함하지 않으면 유의** (Sobel 검정에 의존하지 않음 — 정규성 가정 위반 시 검정력 저하) |
| 대비 검정 | 두 간접효과의 차이(contrast)를 부트스트랩 CI로 검정 (PROCESS Model 4 `contrast` 옵션 / lavaan `:=` 정의) |
| PROCESS 대응 | **Model 4** |
| 보고 항목 | 총효과(c), 직접효과(c′), 간접효과(ab), 95% CI 하한·상한, 완전/부분매개 여부 |

> ⚠️ **"완전매개/부분매개" 용어 사용 주의**: 직접효과의 비유의를 근거로 '완전매개'를 주장하는 것은 검정력 문제에 취약하다. **간접효과의 유의성과 크기를 중심으로 기술**하고, 완전/부분 구분은 부가적으로만 언급한다.

**⚠️ 경쟁가설(rival hypothesis)의 사전 등록**

H3-1(내적통제 → 부정적 FSB 부적)에는 정면 반증이 존재한다. Anseel et al.(2015) 메타분석에서 **자기효능감은 FSB와 ρ = .21**(k=5, 신뢰구간이 0 배제)로 **정적**이며, 내적통제자는 자기효능감이 높으므로 "내적통제자가 피드백을 더 많이 구한다"는 반대 예측이 성립한다.

> **사전 확정 대응**: 반대 방향 경로를 설정한 **대안모형을 명시적으로 함께 추정**하고, **AIC/BIC·적합도로 비교**하여 데이터가 어느 쪽을 지지하는지 보고한다. 단일 방향 가설만 고집하면 결과가 반대로 나올 때 논문 전체가 무너진다. 이론적 구분 근거는 2장에 미리 서술한다: 자기효능감은 '특정 과업 수행 능력에 대한 신념'이고 통제위치는 '결과의 원인 소재에 대한 일반화된 기대'로 **구성개념이 다르다.**

### 7.4 [4단계] 조절효과 검증 (H4 계열)

| 가설 | 조절 경로 | 예측 |
|---|---|---|
| **H4-1** | 실책관리풍토 × **부정적 FSB** → SCB | 풍토 高일 때 정(+)적 관계 **강화** |
| **H4-2** | 실책관리풍토 × **긍정적 FSB** → SCB | H4-1보다 **약함 또는 비유의** (판별 가설) |
| **H5-2** | 직무경력 × 부정적 FSB → SCB | **역U자형** — 중간경력(6–15년)에서 가장 강함 |
| **H5-1a** | 직무경력 × 외적통제 → 부정적 FSB (a경로) | **저경력에서 가장 강함** |

**사전 확정 분석 사양**

| 항목 | 사양 |
|---|---|
| **중심화** | 상호작용항 생성 전 예측변수·조절변수를 **평균중심화(mean-centering)**. 대안으로 직교화(orthogonalization) 병행 가능 |
| **위계적 투입** | 1단계 통제변수 → 2단계 주효과 → 3단계 상호작용항. 각 단계 **ΔR²와 유의성** 보고 |
| **효과크기** | 상호작용항의 **f²** 산출 (f² = ΔR² / (1 − R²_full)) |
| **단순기울기 분석** | 조절변수 **평균 ±1SD**(또는 16/50/84 백분위)에서의 단순기울기와 유의성 |
| **Johnson-Neyman** | 연속형 조절변수(실책관리풍토)에 대해 **유의영역(region of significance)** 을 반드시 병기. ±1SD 2점만 제시하는 것은 임의적이다 |
| **도표** | 조절효과 도표(상호작용 플롯) 제시 |
| **잠재변수 방식** | lavaan에서 **잠재상호작용(latent interaction)** 은 이중중심화 곱항(double mean-centered product indicators) 또는 Mplus의 `XWITH`(LMS) 사용. 수렴 실패 시 **관측변수 평균 기반 상호작용**으로 전환하고 그 사실을 명시 |
| **다중공선성** | 상호작용항 투입 후 **VIF 재산출·보고** |
| **범주형 조절변수(직무경력)** | **지시코딩(indicator coding)** 더미 2개(기준: ≤5년) 생성 후 각 더미 × 예측변수 곱항 투입. PROCESS v4에서는 `mcw = 1` 옵션 |

### 7.5 [5단계] 조절된 매개 검증 (H5 계열) — ⚠️ 본 연구의 완성형 명제

| 가설 | 내용 |
|---|---|
| **H4-3** | 외적통제 → 부정적 FSB → SCB 의 **간접효과가 실책관리풍토에 의해 조절**됨. 풍토가 높을 때에만 유의 |
| **H4-4** | 내적통제의 동일 조절된 매개 **지수 크기 < H4-3** |
| **H5-3** | 통제위치 → 부정적 FSB → SCB 의 간접효과가 **직무경력 집단별로 상이**. **중간경력(6–15년)에서 최대** |
| **H5-4** | 실책관리풍토의 조절매개는 직무경력을 **통제한 후에도 유지**(두 조절 기제의 독립성) |

**PROCESS 모형 번호 — 사전 확정**

| 목적 | PROCESS Model | 근거 |
|---|---|---|
| **주 모형** | **Model 14** (조절변수가 **b경로(M→Y)만** 조절) | 본 연구 이론 서술("실책관리풍토는 피드백추구가 안전시민행동으로 전환되는지를 좌우한다")과 정확히 일치. Preacher, Rucker & Hayes(2007)의 **조절매개 유형 중 'b경로 조절형'** 에 해당 |
| **강건성 검증** | **Model 15** (b경로 + c′경로 동시 조절) | 실책관리풍토가 통제위치 → SCB 직접경로도 조절할 가능성을 배제. **Model 15에서 c′ 조절항이 비유의하면 Model 14 채택의 실증적 근거**가 된다 |
| **a경로 조절(H5-1a)** | **Model 7** | 직무경력이 IV → M 경로를 조절 |
| **직무경력 다범주 조절** | **Model 14 + `mcw = 1`** (indicator coding) | 2개 대비(≤5년 기준 vs 6–15년, vs ≥16년)와 그에 대응하는 **부분조절매개지수(index of partial moderated mediation)** 산출 |
| ⚠️ **b경로 2개 조절변수 동시 투입** | 템플릿 18/19번대가 존재한다고 알려져 있으나, **번호와 구조는 Hayes(2022) 3판 부록 템플릿 도표에서 직접 재확인한 뒤에만 논문에 기재할 것.** 본 분석계획 작성 시점에 매뉴얼 원문을 확인하지 못했다 **[확인 필요]** | — |

**조절변수 2개 처리 — 사전 확정 3단계 위계 전략**

| 단계 | 내용 | 방어력 |
|---|---|---|
| **① 1단계** | 실책관리풍토(연속형)만 조절변수 W로 두고 **Model 14**. **직무경력은 공변량으로 통제** | 기본 |
| **② 2단계** | 직무경력(3범주)을 **다범주 조절변수**로 투입한 Model 14 (`mcw = 1`) | 중 |
| **③ 3단계 (최강)** | **직무경력 3집단 다집단 SEM** (§7.6) | **최고** |

> **무리하게 하나의 템플릿에 두 조절변수를 밀어 넣지 않는다.** 3단계 위계 전략을 3.3절에 명시하고, 세 결과가 수렴함을 보이는 것이 가장 방어력 높은 보고 방식이다.

**⚠️ 반드시 보고할 통계량 (누락 시 치명적 지적 대상)**

| 통계량 | 출처 | 왜 필수인가 |
|---|---|---|
| **조절매개지수 (index of moderated mediation)** 와 그 **부트스트랩 95% CI** | Hayes, A. F. (2015). An index and test of linear moderated mediation. *Multivariate Behavioral Research*, 50(1), 1–22. https://doi.org/10.1080/00273171.2014.962683 **[검증됨]** | ⚠️ **조절변수 수준별 단순 간접효과의 유의/비유의 대조만으로 조절매개를 주장하는 것은 Hayes가 명시적으로 비판한 통계적 오류**다. 심사에서 가장 흔히 지적되는 지점 |
| **조건부 간접효과(conditional indirect effect)** — 풍토 ±1SD 및 Johnson-Neyman 경계값 | Preacher, K. J., Rucker, D. D., & Hayes, A. F. (2007). *Multivariate Behavioral Research*, 42(1), 185–227. https://doi.org/10.1080/00273170701341316 **[검증됨]** | 조건부 효과의 실질적 크기 제시 |
| **조절매개지수 쌍대 대비(pairwise contrast)** — H4-4 검정용 | Hayes(2015) | 외적통제 지수 − 내적통제 지수의 95% CI가 0을 포함하지 않아야 H4-4 지지 |
| **부트스트랩 회수** | **5,000회 (권장 10,000회)**, 편향수정 백분위 CI | |

**구조적 선례(방어 자료)**: Liu et al.(2021)은 동일 형태의 조절된 매개에서 고참여 조건 간접효과 **.24 [.12, .37]**, 저참여 조건 **.08 [−.03, .22](ns)** 를 보고했다. Zhang & Li(2021)의 중국 경찰(N=202) 연구도 고CFC β = .26(유의) / 저CFC β = −.02(비유의)의 동일 구조다. 본 연구 H4-3이 같은 패턴을 보이면 이들을 수렴 증거로 인용한다.

### 7.6 [6단계] 직무경력 3집단 다집단 구조방정식 (Multi-group SEM)

> **왜 상호작용항이 아니라 다집단 SEM인가**: ① 모수 절약(상호작용항 급증 방지), ② **경력 집단 간 통제위치·피드백추구 문항의 해석이 다를 수 있으므로 측정동일성 검증 자체가 학술적 기여**가 된다, ③ 집단별 전체 경로 구조를 동시에 비교할 수 있다.

**사전 확정 절차 (순서를 바꾸지 않는다)**

| 단계 | 모형 | 판정 기준 |
|---|---|---|
| **① 형태동일성** (configural invariance) | 모든 모수 자유추정, 요인구조만 동일 | 적합도 수용 기준(§3.2.1) 충족 |
| **② 측정단위동일성** (metric / weak invariance) | 요인부하량 동등 제약 | **ΔCFI ≤ .01** 그리고 **ΔRMSEA ≤ .015** |
| **③ 절편동일성** (scalar / strong invariance) | 요인부하량 + 절편 동등 제약 | 동일 기준 |
| **④ 구조경로 비교** | 관심 경로(a, b, c′)에 **집단 간 동등 제약**을 가한 모형 vs 자유추정 모형 | **Δχ² 검정** (df = 제약 수), MLR 사용 시 **Satorra-Bentler scaled Δχ²** |

출처: Cheung, G. W., & Rensvold, R. B. (2002). Evaluating goodness-of-fit indexes for testing measurement invariance. *Structural Equation Modeling*, 9(2), 233–255. https://doi.org/10.1207/s15328007sem0902_5 **[검증됨]**

**사전 확정 대응 규칙**

| 상황 | 대응 |
|---|---|
| **metric까지만 성립, scalar 미성립** | **부분동일성(partial invariance)** 을 탐색한다. 비동일 절편을 1~2개 자유화하고 그 문항과 사유를 보고. **metric 성립만으로도 경로계수 비교는 가능**하다 |
| **metric조차 미성립** | 경로계수의 집단 간 비교가 원칙적으로 불가능하다. 이 경우 **다집단 SEM을 포기하고 PROCESS 다범주 조절(2단계)로 회귀**하며, 그 사실과 사유를 4.3절과 5.3절에 명시한다 |
| **집단별 n < 100** | 다집단 SEM 추정이 불안정하다. 집단 병합(예: 6–15년과 ≥16년 병합, 2집단) 또는 경력 연속변수 조절회귀로 전환. **병합 여부는 데이터를 본 뒤가 아니라 표본 확보 시점에 결정**한다 |

**⚠️ 직무경력 조절변수의 교락(confound) 사전 대응 — 반드시 실시**

> Anseel et al.(2015) 메타분석에서 **직무재직기간 ρ = −.15, 조직재직기간 ρ = −.19, 연령 ρ = −.13** 으로 경력이 길수록 FSB 자체가 체계적으로 감소한다. 본 모형은 직무경력을 **조절변수**로 투입하지만, 경력은 동시에 **매개변수(FSB)의 강력한 선행변수**이므로 **조절효과가 실제로는 매개변수 수준 차이에 의한 인공물일 수 있다.**

| 조치 | 내용 |
|---|---|
| **① ANOVA 사전 보고** | 경력 3집단 × 긍정/부정 FSB **평균 차이를 일원배치 ANOVA + 사후검정**으로 보고하고, 경력에 따른 FSB 감소 경향이 본 표본에서도 나타나는지 명시 |
| **② 측정동일성 선행** | 위 ①~③ 절차 |
| **③ 해석 프레임** | Anseel et al.(2015)의 tenure–FSB 부적 관계를 **선제 인용**하고, 논의를 **"경력 집단 간 FSB 기저수준 차이를 통제한 뒤에도 경로계수가 달라지는가"** 로 프레이밍한다. 메타분석 수치를 먼저 제시하면 약점이 논의의 깊이로 전환된다 |

**직무경력 절단점(≤5년 / 6–15년 / ≥16년) 정당화 — 3중 근거**

| 근거 | 내용 |
|---|---|
| **이론적** | Ng & Feldman(2010, *JOM*, 36(5), 1220–1250) **[검증됨]** — 재직기간-수행/시민행동 관계가 **선형이 아니라 정체·감퇴(plateau/decay) 패턴**. 비선형 관계에서는 범주화가 오히려 적절하다. Ng & Feldman(2013, *JVB*, 83(3), 305–314) **[검증됨]** |
| **실증적** | Bena et al.(2013, *BMC Public Health*, 13, 869) **[검증됨]** — 직무재직기간-산업재해 관계가 연령대별로 상이하며 **신규 진입자 위험이 급등** → 저경력 구간 분리 지지 |
| **제도적** | 소방공무원 인사·계급 체계(승진 소요 최저연수, 팀장급 진입 시점, 현장 배치 주기). ⚠️ **연구자가 소방청 인사 규정에서 직접 확인하여 3.3절에 명시할 것** **[확인 필요]** |

**강건성 보강**: 주분석(3집단 범주형)과 별도로, **경력을 연속변수로 투입한 조절회귀** 및 **2차항(경력²) 투입 곡선 모형**을 병행 추정하여 비선형성을 실증하고 3구간 결과와 수렴함을 보인다.

### 7.7 [7단계] 탐색적 분석 — 곡선효과 (H1-5, 부록 배치)

> **왜 필요한가**: 연구목적 문장의 "**과도한** 내적통제 → 단독행동·과잉책임 → 팀 안전 저해"는 본질적으로 **비선형(역U자)** 주장인데, 현 모형은 내적통제를 **선형 예측변수**로 투입한다. 선형 모형에서는 "높을수록 나쁘다" 또는 "높을수록 좋다"만 나올 뿐, "적당히 높을 때 가장 좋고 과도하면 나빠진다"는 **진짜 주장이 구조적으로 검증 불가능**하다.
>
> **"당신 주장은 곡선인데 모형은 직선 아닌가"** 는 방어 불가능한 지적이다.

**사전 확정 대응 — 2안 중 택1 (①을 기본, ②를 부록 탐색으로 병행 권장)**

| 안 | 내용 | 평가 |
|---|---|---|
| **① 순수 조절효과 언어로 재정식화 (기본 권고)** | 주장을 "내적통제의 효과는 피드백추구행동과 실책관리풍토에 **조건부**이며, 부정적 피드백추구가 낮고 실책관리풍토가 낮을 때 그 효과가 **소실되거나 역전**된다"로 재진술. **현 모형 구조와 정합적이며 선형모형으로 방어 가능** | **채택** |
| **② 2차항(quadratic) 탐색적 투입** | 평균중심화 후 내적통제² 항을 투입. 유의 시 변곡점 산출 | **부록 탐색 분석으로 배치** |

**②의 분석 사양**
- 위계적 회귀 1단계 통제변수 → 2단계 내적통제 선형항 → 3단계 **내적통제 제곱항**. **ΔR²와 제곱항 계수의 유의성** 검정.
- **평균중심화 필수** (다중공선성 방지).
- **변곡점(turning point) 위치를 산출하여 표본 관측범위 내에 존재하는지 확인**한다. 범위 밖이면 곡선 주장은 성립하지 않는다.
- 절차 준거: Haans, R. F. J., Pieters, C., & He, Z.-L. (2016). Thinking about U: Theorizing and testing U- and inverted U-shaped relationships in strategy research. *Strategic Management Journal*, 37(7), 1177–1195. https://doi.org/10.1002/smj.2399 **[검증됨 — Crossref 등재 연도는 2015(온라인), 인쇄 발행은 2016년 7호. 참고문헌에는 2016으로 표기하되 출판본에서 최종 확인할 것]**

> ⚠️ **사전 확정**: 연구목적·가설 문장에서 "**과도한** 내적통제"라는 표현을 사용하려면 **반드시 비선형 검증 결과가 있어야 한다.** 표현과 분석을 일치시킬 것. ②를 실시하지 않는다면 "과도한"이라는 표현을 "조건부로 역기능적일 수 있는"으로 바꾼다.

### 7.8 [8단계] 강건성 검증 (Robustness Checks) — 사전 확정 목록

| No. | 검증 | 내용 |
|---|---|---|
| **R1** | **이상치 민감도** | 이상치 포함/제외 모형의 주요 경로 부호·유의성 일치 확인 (§1.3) |
| **R2** | **대안 인과모형** | 역인과 모형(DV → M → IV)을 SEM으로 추정하고 **AIC/BIC·적합도 비교**. 본 모형이 우수함을 제시 |
| **R3** | **경쟁 매개모형** | 긍정 FSB 단독 매개 / 부정 FSB 단독 매개 / 병렬 매개의 적합도 비교 |

### 8A.1 `analysis/01_clean.R` — 자료 정제

```r
# ===== 01_clean.R : 자료 정제 =====
library(tidyverse); library(careless); library(naniar); library(psych)
set.seed(20260914)

raw <- read_csv("data/survey_raw.csv")

# ---- 문항 ID 정의 (item_bank.csv 와 동기화할 것) ----
# ⚠️ WLCS 내적·외적 문항은 설문지에서 연속 블록이 아니다.
#    원척도(Spector, 1988)의 문항 순서를 그대로 유지했기 때문이다.
#    paste0("Q", 8:15) 처럼 범위로 지정하면 6문항(Q12·Q13·Q15 / Q18·Q21·Q22)이
#    반대 요인에 들어가 분석 전체가 무의미해진다. 반드시 명시적으로 나열할 것.
items_int  <- c("Q8", "Q9", "Q10", "Q11", "Q14", "Q18", "Q21", "Q22")   # WLCS 내적통제 8
items_ext  <- c("Q12", "Q13", "Q15", "Q16", "Q17", "Q19", "Q20", "Q23")   # WLCS 외적통제 8
items_pfsb <- paste0("Q", 24:28)   # 긍정 피드백추구 5
items_nfsb <- paste0("Q", 29:33)   # 부정 피드백추구 5
items_emc  <- paste0("Q", 34:41)   # 실책관리풍토 8
items_scb  <- paste0("Q", 42:53)   # 안전시민행동 12
items_all  <- c(items_int, items_ext, items_pfsb, items_nfsb, items_emc, items_scb)
stopifnot(length(items_all) == 46)

# ---- C1: 연구대상 부적합 ----
d <- raw %>% filter(job_type %in% c("화재진압", "구급"))

# ---- C3/C4: 불성실응답 진단 (역채점 이전 원자료에서) ----
d <- d %>%
  mutate(
    ls    = careless::longstring(select(., all_of(items_all))),
    irv   = careless::irv(select(., all_of(items_all))),
    md    = careless::mahad(select(., all_of(items_all)), plot = FALSE, flag = FALSE),
    n_mis = rowSums(is.na(select(., all_of(items_all))))
  )
md_cut <- quantile(d$md, .99, na.rm = TRUE)

# ---- 제외 플래그 (사전 확정 기준, §1.1) ----
d <- d %>% mutate(
  ex_C2 = n_mis >= 5,                       # 결측 5개 이상
  ex_C3 = (irv == 0) | (ls >= 15),          # 직선응답
  ex_C4 = (md > md_cut) & (ls >= 15),       # 무선응답 (동시 충족 ∧)
  ex_C5 = if ("duration_sec" %in% names(d)) duration_sec < 46 * 2 else FALSE,
  ex_C6 = if ("attn_check" %in% names(d)) attn_check != 3 else FALSE,
  ex_C7 = tenure_year > (age - 18),
  excluded = ex_C2 | ex_C3 | ex_C4 | ex_C5 | ex_C6 | ex_C7
)

# ---- 제외 내역 표 (논문 4.1절에 그대로 게재) ----
excl_tbl <- d %>% summarise(across(starts_with("ex_"), sum, .names = "{.col}"),
                            n_excluded = sum(excluded), n_total = n())
print(excl_tbl); write_csv(excl_tbl, "analysis/output/tbl_exclusion.csv")
cat("제외율:", round(100 * excl_tbl$n_excluded / excl_tbl$n_total, 2), "%\n")

dat <- d %>% filter(!excluded)

# ---- 결측 메커니즘 진단 (Little's MCAR) ----
print(naniar::mcar_test(dat %>% select(all_of(items_all))))

# ---- ⚠️ 역채점: 본 연구는 내적·외적을 분리 사용하므로 총점용 역채점을 하지 않는다 ----
# 설문 문항이 원문 그대로 번역된 경우, 내적통제 문항은 이미 '내적 방향'으로 진술되어 있으므로 정채점.
# (원척도 Spector(1988)는 내적 8문항 역채점 후 합산하여 '고득점=외적'으로 채점 → 본 연구 미적용)

# ---- 척도 점수 (문항 평균) ----
dat <- dat %>% mutate(
  INT  = rowMeans(select(., all_of(items_int)),  na.rm = TRUE),
  EXT  = rowMeans(select(., all_of(items_ext)),  na.rm = TRUE),
  PFSB = rowMeans(select(., all_of(items_pfsb)), na.rm = TRUE),
  NFSB = rowMeans(select(., all_of(items_nfsb)), na.rm = TRUE),
  EMC  = rowMeans(select(., all_of(items_emc)),  na.rm = TRUE),
  SCB  = rowMeans(select(., all_of(items_scb)),  na.rm = TRUE),
  tenure_grp = factor(case_when(tenure_year <=  5 ~ "G1_5이하",
                                tenure_year <= 15 ~ "G2_6to15",
                                TRUE              ~ "G3_16이상"),
                      levels = c("G1_5이하", "G2_6to15", "G3_16이상"))
)

# ---- 이상치 표시 (제거하지 않음 — 민감도 분석용) ----
core <- c("INT","EXT","PFSB","NFSB","EMC","SCB")
dat <- dat %>% mutate(
  md_core  = careless::mahad(select(., all_of(core)), plot = FALSE, flag = FALSE),
  outlier  = md_core > qchisq(.999, df = length(core))
)
cat("이상치 표시 건수:", sum(dat$outlier), "\n")

# ---- 정규성 (문항 수준) ----
norm_tbl <- psych::describe(dat %>% select(all_of(items_all)))[, c("mean","sd","skew","kurtosis")]
print(norm_tbl); write.csv(norm_tbl, "analysis/output/tbl_normality.csv")
cat("왜도|2| 초과:", sum(abs(norm_tbl$skew) > 2),
    "/ 첨도|7| 초과:", sum(abs(norm_tbl$kurtosis) > 7), "\n")
cat("→ 하나라도 초과하면 CFA/SEM 추정법을 MLR 로 전환할 것 (§1.6)\n")

# ---- 천장·바닥효과 경보 (특히 SCB) ----
ceiling_items <- norm_tbl %>% as.data.frame() %>%
  rownames_to_column("item") %>% filter(mean > 4.3 | mean < 2.0)
print(ceiling_items)

saveRDS(dat, "data/analysis_clean.rds")
sessionInfo()
```

### 8A.2 `analysis/02_validity.R` — EFA / CFA 경쟁모형 / 타당도 / 신뢰도

```r
# ===== 02_validity.R : 타당성·신뢰도 =====
library(lavaan); library(semTools); library(psych); library(tidyverse)
set.seed(20260914)
dat <- readRDS("data/analysis_clean.rds")
EST <- "MLR"   # §1.6 정규성 점검 결과에 따라 "ML" 또는 "MLR"

# ---------- (1) EFA : 평행분석 + 주축분해 + 사각회전 ----------
emc_fsb <- dat %>% select(all_of(c(paste0("Q",24:33), paste0("Q",34:41))))  # 교차부하 사전 탐지
print(psych::KMO(emc_fsb)); print(psych::cortest.bartlett(cor(emc_fsb, use="pairwise"), n=nrow(dat)))
psych::fa.parallel(emc_fsb, fm = "pa", fa = "fa")
efa1 <- psych::fa(emc_fsb, nfactors = 2, rotate = "promax", fm = "pa")
print(efa1$loadings, cutoff = .30)   # 교차부하 > .40 문항 식별

# ---------- (2) CFA 경쟁모형 : 통제위치 WLCS ----------
M1 <- ' LOC =~ Q8+Q9+Q10+Q11+Q12+Q13+Q14+Q15+Q16+Q17+Q18+Q19+Q20+Q21+Q22+Q23 '
M2 <- ' INT =~ Q8+Q9+Q10+Q11+Q14+Q18+Q21+Q22
        EXT =~ Q12+Q13+Q15+Q16+Q17+Q19+Q20+Q23 '
M3 <- ' LOC =~ Q8+Q9+Q10+Q11+Q12+Q13+Q14+Q15+Q16+Q17+Q18+Q19+Q20+Q21+Q22+Q23
        WRD =~ Q8+Q9+Q10+Q11+Q14+Q18+Q21+Q22          # 진술방향 방법요인 (긍정진술 뭉치)
        LOC ~~ 0*WRD '
M4 <- ' EXT =~ Q12+Q13+Q15+Q16+Q17+Q19+Q20+Q23
        IN1 =~ Q8+Q9+Q10+Q11                           # 노력-성과 신념  (경험적 배정)
        IN2 =~ Q14+Q18+Q21+Q22 '                       # 조직 내 영향력 신념

fitlist <- list(M1 = M1, M2 = M2, M3 = M3, M4 = M4)
fit_tbl <- map_dfr(names(fitlist), function(nm) {
  f <- try(cfa(fitlist[[nm]], data = dat, estimator = EST, missing = "fiml"), silent = TRUE)
  if (inherits(f, "try-error") || !lavInspect(f, "converged"))
    return(tibble(model = nm, note = "수렴 실패"))
  ms <- fitMeasures(f, c("chisq.scaled","df","cfi.robust","tli.robust",
                         "rmsea.robust","rmsea.ci.lower.robust","rmsea.ci.upper.robust",
                         "srmr","aic","bic"))
  tibble(model = nm, chisq = ms[1], df = ms[2], chisq_df = ms[1]/ms[2],
         CFI = ms[3], TLI = ms[4], RMSEA = ms[5],
         RMSEA_lo = ms[6], RMSEA_hi = ms[7], SRMR = ms[8], AIC = ms[9], BIC = ms[10])
})
print(fit_tbl); write_csv(fit_tbl, "analysis/output/tbl_cfa_wlcs.csv")

# ★ 사전 확정 판정 (§3.2.2 A)
fit_M2 <- cfa(M2, data = dat, estimator = EST, missing = "fiml")
r_int_ext <- lavInspect(fit_M2, "cor.lv")["INT","EXT"]
cat("내적-외적 잠재상관 r =", round(r_int_ext, 3),
    ifelse(r_int_ext <= -.70, " → ⚠️ 단일 연속선 반증. 2요인 주장 철회 검토",
                              " → 2요인 분리 유지 가능"), "\n")

# ---------- (3) CFA 경쟁모형 : 안전시민행동 SCB ----------
S1 <- ' SCB =~ Q42+Q43+Q44+Q45+Q46+Q47+Q48+Q49+Q50+Q51+Q52+Q53 '
S2 <- ' HELP =~ Q42+Q43
        VOIC =~ Q44+Q45
        STEW =~ Q46+Q47
        WHIS =~ Q48+Q49
        CIVI =~ Q50+Q51
        INIT =~ Q52+Q53 '
S3 <- ' HELP =~ Q42+Q43
        VOIC =~ Q44+Q45
        STEW =~ Q46+Q47
        WHIS =~ Q48+Q49
        CIVI =~ Q50+Q51
        INIT =~ Q52+Q53
        AFFIL  =~ HELP + STEW + WHIS + CIVI     # 친화지향 (2차 요인)
        CHALL  =~ VOIC + INIT '                 # 도전지향 (2차 요인)
# S4 : parcel 방식 — dat 에 parcel 변수 사전 생성 후 1요인 CFA

for (nm in c("S1","S2","S3")) {
  f <- try(cfa(get(nm), data = dat, estimator = EST, missing = "fiml"), silent = TRUE)
  cat("\n===", nm, "===\n")
  if (inherits(f, "try-error")) { cat("추정 실패\n"); next }
  print(fitMeasures(f, c("cfi.robust","tli.robust","rmsea.robust","srmr","aic","bic")))
  hw <- lavInspect(f, "est")$theta; if (any(diag(hw) < 0)) cat("⚠️ Heywood case (음의 오차분산) 발생\n")
}
# ⚠️ S2(차원당 2문항 6요인)는 Heywood/수렴실패가 예상된다. 실패 사실 자체를 투명 보고할 것 (§3.2.2 B)

# ---------- (4) 전체 측정모형 ----------
MM <- ' INT  =~ Q8+Q9+Q10+Q11+Q14+Q18+Q21+Q22
        EXT  =~ Q12+Q13+Q15+Q16+Q17+Q19+Q20+Q23
        PFSB =~ Q24+Q25+Q26+Q27+Q28
        NFSB =~ Q29+Q30+Q31+Q32+Q33
        EMC  =~ Q34+Q35+Q36+Q37+Q38+Q39+Q40+Q41
        SCB  =~ Q42+Q43+Q44+Q45+Q46+Q47+Q48+Q49+Q50+Q51+Q52+Q53 '
fit_mm <- cfa(MM, data = dat, estimator = EST, missing = "fiml")
summary(fit_mm, fit.measures = TRUE, standardized = TRUE)

# ---------- (5) 신뢰도 : α, ω, AVE, CR ----------
rel <- semTools::compRelSEM(fit_mm)                 # 복합신뢰도(ω 계열)
ave <- semTools::AVE(fit_mm)
print(round(rel, 3)); print(round(ave, 3))
cat("AVE ≥ .50 충족 여부:\n"); print(ave >= .50)

# Cronbach α (하위척도별)
for (s in list(INT=items_int, EXT=items_ext,
               PFSB=paste0("Q",24:28), NFSB=paste0("Q",29:33),
               EMC=paste0("Q",34:41), SCB=paste0("Q",42:53))) {
  a <- psych::alpha(dat[, s], check.keys = FALSE)
  cat(names(a$total), "\n"); print(round(a$total$raw_alpha, 3))
  print(round(a$item.stats[, c("r.drop")], 3))     # 문항-총점 상관 (기준 ≥ .30)
}

# ---------- (6) 판별타당도 : Fornell-Larcker + HTMT ----------
cor_lv <- lavInspect(fit_mm, "cor.lv")
fl <- cor_lv; diag(fl) <- sqrt(ave)                 # 대각선 = √AVE
cat("\n[Fornell-Larcker] 대각선(√AVE)이 같은 행·열의 상관보다 커야 함\n"); print(round(fl, 3))

htmt_mat <- semTools::htmt(MM, data = dat)
cat("\n[HTMT] 기준 < .85\n"); print(round(htmt_mat, 3))
cat("HTMT ≥ .85 위반 쌍:\n"); print(which(abs(htmt_mat) >= .85 & htmt_mat != 1, arr.ind = TRUE))
# ★ 사전 지정 필수 점검 쌍 (§3.4): INT~EXT, INT~NFSB, NFSB~EMC, EMC~SCB, PFSB~NFSB

sessionInfo()
```

### 8A.3 `analysis/03_cmb.R` — 공통방법편향

```r
# ===== 03_cmb.R : 공통방법편향 =====
library(lavaan); library(tidyverse)
set.seed(20260914)
dat <- readRDS("data/analysis_clean.rds"); EST <- "MLR"
source("analysis/_models.R")   # MM 정의 재사용

items_all <- c(paste0("Q", 8:53))

# ---------- [1단계] Harman 단일요인 CFA ----------
H1 <- paste0("CMF =~ ", paste(items_all, collapse = " + "))
fit_h1 <- cfa(H1, data = dat, estimator = EST, missing = "fiml")
print(fitMeasures(fit_h1, c("cfi.robust","tli.robust","rmsea.robust","srmr")))
cat("→ 단일요인 모형이 기준에 크게 미달해야 CMB 위협이 작다고 판단 (최소 요건일 뿐)\n")
# EFA 방식 보조: 회전 없는 1요인 설명분산 < 50%
ev <- eigen(cor(dat[, items_all], use = "pairwise"))$values
cat("제1요인 설명분산 =", round(100 * ev[1] / sum(ev), 2), "% (기준 < 50%)\n")

# ---------- [2단계] CFA marker technique (Williams et al., 2010) ----------
# ⚠️ 마커변수 문항(MK1~MK3)이 설문에 있어야 실행 가능 (§1.5 ①)
if (all(c("MK1","MK2","MK3") %in% names(dat))) {
  base_m   <- paste0(MM, "\n MK =~ MK1 + MK2 + MK3")
  fit_base <- cfa(base_m, data = dat, estimator = EST, missing = "fiml")

  # Method-C : 마커요인의 모든 실질문항 적재를 동일(equal)하게 제약
  loads_c <- paste0("MK =~ ", paste0("m*", items_all, collapse = " + "))
  fit_C <- cfa(paste(base_m, loads_c, sep = "\n"), data = dat, estimator = EST, missing = "fiml")

  # Method-U : 적재 자유추정
  loads_u <- paste0("MK =~ ", paste(items_all, collapse = " + "))
  fit_U <- cfa(paste(base_m, loads_u, sep = "\n"), data = dat, estimator = EST, missing = "fiml")

  print(anova(fit_base, fit_C))   # 방법효과 존재 여부
  print(anova(fit_C,    fit_U))   # 방법효과 균질성
  cat("→ Method-R(구조계수 제약) 비교로 실질 경로계수 영향까지 판정할 것\n")

  # Lindell-Whitney 보정 (보조)
  rM <- min(abs(cor(dat[, c("INT","EXT","PFSB","NFSB","EMC","SCB")],
                    rowMeans(dat[, c("MK1","MK2","MK3")]), use = "pairwise")))
  cat("marker 최소 상관 rM =", round(rM, 3), "→ 부분상관 보정 후 유의성 유지 확인\n")
} else {
  cat("⚠️ 마커변수 문항이 없다. CFA marker technique 실행 불가.\n",
      "   설문 배포 전에 반드시 추가할 것 (§1.5 ①). 배포 후에는 복구 불가능.\n")
}

# ---------- [3단계] ULMC ----------
ulmc <- paste(MM, paste0("CMV =~ ", paste(items_all, collapse = " + ")),
              "CMV ~~ 0*INT\nCMV ~~ 0*EXT\nCMV ~~ 0*PFSB\nCMV ~~ 0*NFSB\nCMV ~~ 0*EMC\nCMV ~~ 0*SCB",
              sep = "\n")
fit_u <- try(cfa(ulmc, data = dat, estimator = EST, missing = "fiml"), silent = TRUE)
if (!inherits(fit_u, "try-error") && lavInspect(fit_u, "converged")) {
  fit_mm <- cfa(MM, data = dat, estimator = EST, missing = "fiml")
  cat("ΔCFI =", round(fitMeasures(fit_u,"cfi.robust") - fitMeasures(fit_mm,"cfi.robust"), 4),
      " (기준: < .01 이면 CMB 심각하지 않음)\n")
} else cat("ULMC 수렴 실패 — 그 사실을 보고하고 marker 결과를 주 근거로 삼을 것\n")
sessionInfo()
```

```r
dat <- dat %>% mutate(

  PFSB_EMC = PFSB_c * EMC_c,
  INT_sq   = INT_c^2                 # §7.7 탐색적 곡선효과

# ===================================================================
# (A) H3 : 병렬다중매개 + 부트스트랩 5,000 (PROCESS Model 4 대응)
# ===================================================================
med_model <- '
  # a 경로
  PFSB ~ a1*INT_c + a2*EXT_c + sex + age + job_type
  NFSB ~ a3*INT_c + a4*EXT_c + sex + age + job_type
  # b 경로 및 직접효과
  SCB  ~ b1*PFSB + b2*NFSB + cp1*INT_c + cp2*EXT_c + sex + age + job_type
  PFSB ~~ NFSB

  # 간접효과
  ind_INT_P  := a1*b1          # 내적 → 긍정 → SCB
  ind_INT_N  := a3*b2          # H3-1 : 내적 → 부정 → SCB  (부적 예측)
  ind_EXT_P  := a2*b1
  ind_EXT_N  := a4*b2          # H3-2 : 외적 → 부정 → SCB  (정적 예측) ★핵심
  # 경쟁 매개 대비 (H3-3)
  con_EXT    := ind_EXT_N - ind_EXT_P
  con_INT    := ind_INT_N - ind_INT_P
  # 총효과
  tot_INT    := cp1 + ind_INT_P + ind_INT_N
  tot_EXT    := cp2 + ind_EXT_P + ind_EXT_N
'
fit_med <- sem(med_model, data = dat, estimator = "ML", missing = "fiml",
               se = "bootstrap", bootstrap = NBOOT)
summary(fit_med, standardized = TRUE, rsquare = TRUE)
print(parameterEstimates(fit_med, boot.ci.type = "bca.simple", level = .95) %>%
        filter(op == ":=") %>% select(label, est, ci.lower, ci.upper, pvalue))
cat("→ 95% CI 가 0을 포함하지 않으면 유의 (Sobel 미사용)\n")

# ---- H1-2 vs H1-3 경로계수 차이 검정 (Δχ², df=1) ----
fit_free <- sem(med_model, data = dat, estimator = EST, missing = "fiml")
med_eq   <- gsub("a3\\*INT_c", "aEQ*INT_c", med_model)
med_eq   <- gsub("a4\\*EXT_c", "aEQ*EXT_c", med_eq)
fit_eq   <- sem(med_eq, data = dat, estimator = EST, missing = "fiml")
print(lavTestLRT(fit_eq, fit_free))   # 유의하면 두 경로가 서로 다른 기제

# (B) H4-1 / H4-3 : 조절된 매개 (PROCESS Model 14 대응)
#     실책관리풍토(EMC)가 b경로(M→Y)를 조절
# ===================================================================
modmed <- '
  NFSB ~ a*EXT_c + a2*INT_c + sex + age + job_type
  SCB  ~ b1*NFSB + b2*EMC_c + b3*NFSB_EMC + cp*EXT_c + cp2*INT_c + sex + age + job_type

  idx_modmed := a*b3                                   # ★ 조절매개지수 (Hayes, 2015)
  ind_lo     := a*(b1 + b3*(-1*EMCSD))
  ind_mean   := a*b1
  ind_hi     := a*(b1 + b3*( 1*EMCSD))
  idx_INT    := a2*b3                                  # H4-4 : 내적통제 지수
  idx_diff   := idx_modmed - idx_INT                   # H4-4 쌍대 대비
'
EMCSD <- sd(dat$EMC_c, na.rm = TRUE)
fit_mm14 <- sem(gsub("EMCSD", EMCSD, modmed), data = dat, estimator = "ML",
                missing = "fiml", se = "bootstrap", bootstrap = NBOOT)
print(parameterEstimates(fit_mm14, boot.ci.type = "bca.simple") %>%
        filter(op == ":=") %>% select(label, est, ci.lower, ci.upper))
cat("★ idx_modmed 의 95% CI 가 0을 포함하지 않아야 조절된 매개 성립 (Hayes, 2015)\n",
    "  ind_lo / ind_hi 의 유의·비유의 대조만으로 조절매개를 주장하지 말 것\n")

# ---- 강건성 : Model 15 (b경로 + c'경로 동시 조절) ----
modmed15 <- gsub("cp\\*EXT_c", "cp*EXT_c + d1*EXT_EMC", modmed)
dat$EXT_EMC <- dat$EXT_c * dat$EMC_c
fit_mm15 <- sem(gsub("EMCSD", EMCSD, modmed15), data = dat,
                estimator = EST, missing = "fiml")
print(parameterEstimates(fit_mm15) %>% filter(label == "d1"))
cat("→ d1(c'경로 조절)이 비유의하면 Model 14 채택의 실증 근거가 된다\n")

# ---- Johnson-Neyman 유의영역 (조절변수 연속형) ----
library(interactions)
m_jn <- lm(SCB ~ NFSB_c * EMC_c + sex + age + job_type, data = dat)
print(interactions::johnson_neyman(m_jn, pred = NFSB_c, modx = EMC_c))
interactions::interact_plot(m_jn, pred = NFSB_c, modx = EMC_c, interval = TRUE)

# ---- 위계적 회귀 (ΔR², f²) ----
s1 <- lm(SCB ~ sex + age + job_type, data = dat)
s2 <- update(s1, . ~ . + NFSB_c + EMC_c)

print(anova(s1, s2, s3))
dR2 <- summary(s3)$r.squared - summary(s2)$r.squared
```

```r
      " ΔRMSEA =", round(fitMeasures(b,"rmsea.robust") - fitMeasures(a,"rmsea.robust"), 4), "\n")

}
cmp(cfg, met, "metric"); cmp(met, sca, "scalar")

        EXT  =~ Q12+Q13+Q15+Q16+Q17+Q19+Q20+Q23

# 전체 a경로 LRT 가 유의해도 어느 쪽(외적/내적) 때문인지는 알 수 없으므로 분리한다.
```

### 8A.6 `analysis/07_power.R` — 검정력·표본수 (Monte Carlo)

```r
# ===== 07_power.R : Monte Carlo 검정력 =====
library(lavaan); library(tidyverse)
set.seed(20260914)

# 모집단 모형 (선행연구 기반 보수적 효과크기: a = .25, b = .25, 조절 b3 = .15)
pop <- '
  M ~ 0.25*X
  Y ~ 0.25*M + 0.10*X + 0.15*XW + 0.20*W
  X ~~ 1*X ; W ~~ 1*W ; XW ~~ 1*XW ; M ~~ 0.94*M ; Y ~~ 0.85*Y
'
ana <- ' M ~ a*X
         Y ~ b*M + cp*X + b3*XW + W
         idx := a*b3
         ind := a*b '

run_power <- function(n, nrep = 500, nboot = 1000) {
  hits <- replicate(nrep, {
    d <- simulateData(pop, sample.nobs = n)
    f <- try(sem(ana, data = d, se = "bootstrap", bootstrap = nboot), silent = TRUE)
    if (inherits(f, "try-error")) return(c(NA, NA))
    pe <- parameterEstimates(f, boot.ci.type = "bca.simple") %>% filter(op == ":=")
    c(ind = as.numeric(pe$ci.lower[pe$label=="ind"] > 0 | pe$ci.upper[pe$label=="ind"] < 0),
      idx = as.numeric(pe$ci.lower[pe$label=="idx"] > 0 | pe$ci.upper[pe$label=="idx"] < 0))
  })
  rowMeans(hits, na.rm = TRUE)
}
for (n in c(200, 300, 400, 500, 600)) {
  p <- run_power(n, nrep = 200, nboot = 500)   # 최종 보고 시 nrep=1000, nboot=5000
  cat(sprintf("N = %3d  매개 검정력 = %.3f  조절매개 검정력 = %.3f\n", n, p[1], p[2]))
}
# 목표: 검정력 ≥ .80 을 만족하는 최소 N 을 보고 (Muthén & Muthén, 2002)
sessionInfo()
```

> **집단 배분 주의**: 소방 인력 구조상 특정 경력 구간에 인원이 편중될 수 있다. 표집 단계에서 **경력 구간별 할당 표집(quota sampling)** 을 적용하여 집단 간 n 불균형을 사전에 방지한다. 수집 도중 특정 집단이 100명에 미달할 것으로 예상되면 **그 시점에** 추가 표집 계획을 세운다(수집 종료 후 집단을 병합하는 사후 결정을 피하기 위함).

### 9.3 Monte Carlo 검정력 분석 (사전 실시 권고)

`analysis/07_power.R`(§8A.6)을 **자료 수집 전에 실행**하여, 선행연구 기반 보수적 효과크기(a = .25, b = .25, 조절 b3 = .15) 하에서 검정력 .80을 만족하는 최소 N을 산출하고 그 결과를 3.3.2절에 **표로 게재**한다. 사전 검정력 분석 결과가 논문에 있으면 "표본이 충분한가"라는 질문이 사전 종결된다.

| **C5** | **⚠️ [현재 가장 큰 실질적 취약점] "국내 소방공무원 대상 선행연구 검토가 부실하다"** | 본 분석계획의 근거 조사에서 Crossref로 확인된 **국내 소방공무원 논문은 직무스트레스·임파워먼트·사회적지지 계열에 집중**되어 있고(Choi, 2025, *Fire Science and Engineering*, 39(1), 69–76; Shin, 2015, 29(6), 139–146; Choi, Ji & Kim, 2012, *JKAIS*, 13(10), 4917–4926), **'소방공무원 안전행동/안전시민행동' 주제의 국내 실증연구는 확증하지 못했다**(KCI 포털 검색어 미반영, RISS·DBpia 인증 필요). **★대응: 연구자가 RISS·KCI·DBpia에서 직접 검색하여 보완할 것.** 검색어: '소방공무원 안전행동', '소방공무원 안전문화', '소방공무원 안전풍토', '소방공무원 안전의식', '119구급대원 안전', '소방공무원 통제소재/통제위치'. **★절대 기억에 의존해 국내 문헌을 생성하지 말 것 — 국내 심사위원은 국내 선행연구를 직접 확인하므로 허위 인용은 즉시 발각된다.** 임시 보완책으로 **국내 타 직군 안전행동 연구 중 본 연구와 동일 구조(매개 + 풍토 조절)의 선례**를 방법론 정당화에 활용: Jung, Kim & Go(2016, 한국안전경영과학회지, 18(1), 89–97) — 물리적 환경 → 안전행동, 직무스트레스 매개 + **안전풍토 조절**; Youn & Park(2022, 한국항공운항학회지, 30(4), 105–116) — 항공정비사 안전문화 → 안전행동 | **연구자 직접 수행 필요 (§14 다음 단계)** |
| **C6** | **"직무경력 3구간(≤5년 / 6–15년 / ≥16년)의 절단점 근거는 무엇인가?"** | ⓐ **이론적** — Ng & Feldman(2010) 재직기간–수행/시민행동 관계의 **비선형성(정체·감퇴)**; 비선형 관계에서는 범주화가 오히려 적절 ⓑ **실증적** — Bena et al.(2013) **신규 진입 초기 재해 위험 급등** → 저경력 구간 분리 지지 ⓒ **제도적** — 소방공무원 인사·계급 체계(승진 소요 최저연수, 팀장급 진입 시점) **[연구자 확인 필요]** ⓓ **통계적 보강** — 경력을 **연속형으로 투입한 모형**과 **2차항(경력²) 곡선 모형**을 병행 추정하여 비선형성을 실증하고 3구간 결과와 수렴함을 제시. **★절단점을 사후적으로 데이터에 맞춰 정하지 말고 사전 등록 수준으로 3장에 확정 기술할 것** | **§7.6의 절단점 정당화 3중 근거 + 강건성 보강** |
| **C7** | **"안전시민행동은 자발적 부가행동인데, 규정 준수(안전순응)를 측정하지 않고 SCB만 종속변수로 두는 것이 타당한가? 실제 사고 감소와 연결되는가?"** | ⓐ **이론적 방어** — Didla, Mearns & Flin(2009)이 SCB를 '**규정 준수를 넘어선 선제적 위험관리**'로 정의했으며, **소방 현장은 사전 규정이 존재하지 않는 비정형 상황이 본질**이므로 compliance 측정으로는 이 맥락의 안전수행을 포착할 수 없다. | **C8** | **"통제위치를 6점에서 5점으로, 안전시민행동을 빈도형에서 동의형으로 바꿨는데 척도 타당도가 유지되는가?"** | 3장에서 **변경 사유**(응답 부담 감소, 전 척도 반응양식 통일을 통한 측정오차 감소)를 명시하고, **번역-역번역(Brislin, 1970 **[검증됨]**) 절차와 소방 실무자·전문가 내용타당도 검토(CVI/CVR) 과정을 상세 기술.** 본조사 전 **예비조사(n ≥ 50)** 로 신뢰도(α, CR)와 요인구조를 확인하고, 본조사에서 **CFA로 원척도 요인구조(WLCS 내적/외적 2요인, SCB 6차원)가 재현되는지 검증**하여 보고. 특히 **WLCS 역채점 문항 처리와 내적/외적 2요인 구조의 한국 표본 재현 여부는 별도 점검**(§1.4, §3.2.2 A) | **§1.4 + §3.2.2 + §5.1** |

## 12. 결과 시나리오별 해석 규칙 (사전 확정 — HARKing 방지)

> **원칙**: 아래 해석 규칙은 **자료를 보기 전에** 확정한다. 결과를 본 뒤 가설을 바꾸거나 유리한 해석만 선택하는 것(HARKing)을 방지하기 위함이며, 심사에서 "결과에 맞춰 이야기를 지어낸 것 아닌가"라는 의심을 원천 차단한다.

### 12.1 측정모형 시나리오

| 시나리오 | 사전 확정 대응 |
|---|---|
| **WLCS M2(2요인) 최우수** | 2요인 분리 채택. 정당화 완료. 계획대로 진행 |
| **WLCS M3(방법요인) ≥ M2** | **2요인 해석 철회.** 16문항 총점(단일 externality)으로 회귀하고 H1-1~H1-4를 '통제위치(단일) → 긍정/부정 FSB' 2경로로 재구성. 이 전환 규칙이 **사전에 명시되어 있으므로 HARKing이 아니다** |
| **WLCS M4(3요인) 최우수** | 3요인 채택 + Internal-1/Internal-2 명명. **이론적 정교화(기여)로 전환**하고, 두 내적 하위차원의 차별적 효과를 추가 분석 |
| **SCB S3(2차 요인 2개) 지지** | **계획대로 친화지향/도전지향 분리 종속변수 사용.** 본 연구 핵심 논리의 정밀 검증 가능 |
| **SCB S2(6요인) 수렴 실패 / Heywood** | **실패 사실 자체를 투명 보고**하고 S3 또는 S4(6 parcel 1요인)로 전환. 6차원을 '내용 표집 틀'로 성격 규정 |
| **EMC E2(2요인) 우수** | **실책관리풍토 / 실책회피풍토 2개 하위차원을 각각 조절변수로 투입.** 정교화로 프레이밍 |
| **긍정 FSB가 2요인 분리** | 사후 명명임을 명시하고 '자기확증형 피드백추구' / '인정추구'로 분리 검토. 인정추구는 **인상관리 동기**로 해석하고 본 모형에서 제외 검토 |
| **판별타당도 위반 (HTMT ≥ .85)** | 해당 쌍의 문항 내용 중복을 진단하고 ⓐ 중복 문항 제거 후 재추정 ⓑ 그래도 위반이면 **두 구인을 하나로 통합**하고 해당 가설을 철회·재구성. 4.2절에 전 과정 보고 |

### 12.2 가설검증 시나리오

| 시나리오 | 사전 확정 해석 |
|---|---|
| **H1-2 유의(부적) + H1-3 유의(정적)** | **최상 시나리오.** 반론 서사 완성. 두 경로계수 차이 Δχ² 검정으로 '서로 다른 기제' 입증 |
| **H1-2 비유의, H1-3 유의** | **여전히 성립.** H1-3만으로 "외적통제가 무기력이 아니다"라는 핵심 반론은 성립한다. H1-2 비유의는 §7.7의 곡선효과로 재검토하고, 곡선이 유의하면 **TMGT 명제 지지 증거**로 전환(선형 비유의 + 제곱항 유의 = 전형적 역U자 패턴) |
| **H1-2 유의하되 방향이 정(+)** | **경쟁가설(자기효능감 채널) 지지.** 정직하게 보고하고, 2장에 사전 서술한 경쟁가설 논의를 5장에서 전면화. "본 연구는 내적통제의 ego cost 채널 가설을 지지하지 못했으며, 자기효능감 채널이 우세함을 시사한다"로 기술. **가설을 사후에 바꾸지 않는다** |
| **H2-2 > H2-1 (부정 우위)** | Ashford & Tsui(1991)의 비대칭 발견 재현. 국내 선례(허창구 등, 2021: 부정 FSB만 혁신행동에 정적 영향, 긍정은 무의미)와 수렴 |
| **H3-2(외적→부정FSB→SCB) 간접효과 유의** | **본 연구 반론의 중심 명제 지지.** 5장 시사점의 핵심 |
| **간접효과 전부 비유의** | 조절효과(H4·H5) 수준으로 논의 이동. **"주효과가 아니라 조건부 효과"** 라는 더 정교한 결론으로 재구성(§11.1 A6의 세 번째 보험) |
| **H4-3 조절매개지수 유의** | **완성형 명제 성립**: "외적 통제성향은 그 자체로 안전에 유리한 것이 아니라, 부정적 피드백을 안전하게 구할 수 있는 조직 풍토가 갖추어졌을 때 비로소 안전시민행동으로 전환된다." **특성론적 통념을 맥락주의적(contextualist) 명제로 대체** |
| **다집단 SEM metric 미성립** | 다집단 SEM 포기 → PROCESS 다범주 조절로 회귀. **사유를 4.3절·5.3절에 명시**(§7.6 규칙) |
| **친화지향 SCB와 도전지향 SCB의 효과가 상반** | **★본 연구 핵심 논리의 가장 강력한 지지 증거.** "내적통제는 도전지향(개인이 나서는 행동)을 높이나 친화지향(팀과 함께 가는 행동)은 높이지 못한다"를 직접 입증. 단일 총점 모형에서 두 효과가 상쇄되었음을 함께 제시(§7.8 R7) |
