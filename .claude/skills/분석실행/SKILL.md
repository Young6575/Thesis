# 통계분석 실행 절차

분석계획은 `docs/03_분석계획.md` 에 사전 확정되어 있다. **계획을 먼저 읽어라.**
결과를 보고 나서 분석을 바꾸면 HARKing 이 된다.

## 원칙

1. **원자료를 외부에 올리지 마라.** 로컬에서만 처리한다.
   `data/raw/` 는 `.gitignore` 에 있다. 이 상태를 유지한다.
2. **경고 메시지를 삼키지 마라.** Heywood case(음의 오차분산), 수렴 실패,
   비정상 표준오차는 **반드시 연구자에게 그대로 보고**한다. 조용히 넘어가면
   틀린 결과가 논문에 실린다.
3. 분석계획에 없는 분석을 임의로 추가하지 마라. 필요하면 **탐색적 분석**이라고
   명시하고 별도 절에 둔다.

## 순서

```r
# 00_import.R    자료 읽기, 변수명 표준화
# 01_clean.R     불성실응답 제거(직선 응답·응답시간), 결측, 역채점
# 02_descr.R     표본 기초통계 (4.1절)
# 03_cfa.R       측정모형 CFA — ★ WLCS 는 1·2·3요인 경쟁모형 비교 필수
# 04_reliab.R    α, 복합신뢰도(CR), AVE
# 05_validity.R  판별타당도 (Fornell-Larcker, HTMT)
# 06_cmv.R       공통방법편향 (Harman 단일요인 검정만. 마커변수·역문항 모두 미채택)
# 07_corr.R      기술통계·상관 (4.2절)
# 08_sem.R       구조모형, 매개 부트스트랩 5,000회
# 09_modmed.R    조절·조절된 매개 (Model 14), 조절매개지수
# 10_multigroup.R 경력 3집단 다집단 SEM + 절단점 민감도 분석
# 99_tables.R    APA 형식 표 출력
```

각 스크립트는 `analysis/` 에 저장하고, 출력은 `analysis/output/` 에 둔다(커밋 제외).

## 자주 틀리는 것

| 함정 | 확인 |
|---|---|
| lavaan `group.partial` | 제약을 **푸는** 목록이다. 검정할 경로만 제약으로 남기고 나머지(직접경로 포함)를 전부 나열해야 교락이 없다 |
| 상호작용항 | lavaan 에 `:` 연산자가 없다. 평균중심화 후 곱셈 변수를 직접 만든다 |
| 2문항 척도의 α | 문항간 상관의 Spearman-Brown 변환일 뿐이다. α 대신 **문항간 상관**을 함께 보고한다 |
| 부트스트랩 | 편향수정(bias-corrected) 95% CI. 반복 5,000회 이상 |
| 다범주 조절변수 | 더미 지시코딩. 조절매개지수가 **2개** 나온다 |

## 보고

결과는 **APA 형식 표**로 만들고, 각 가설에 대해
`지지 / 부분지지 / 기각` 을 명시한다.
**가설과 어긋난 결과를 숨기지 마라.** 기각된 가설은 5장 논의의 재료다.
