# 선행연구 정리 절차

문헌고찰은 "많이 읽는 것"이 아니라 **같은 틀로 비교 가능하게 쌓는 것**이다.
매번 다른 형식으로 요약하면 2장을 쓸 때 다시 읽어야 한다.

## 절차

### 1. 실재부터 확인한다

```bash
python3 tools/verify_citations.py --doi <DOI>
# DOI 를 모르면
python3 tools/verify_citations.py --query "제목" --author 성 --year 연도
```

**검증 실패하면 정리하지 마라.** 존재하지 않는 논문을 매트릭스에 넣으면
나중에 그게 어디서 왔는지 추적할 수 없게 된다.

### 2. 고정된 틀로 추출한다

| 항목 | 내용 |
|---|---|
| 서지 | 저자(연도). 제목. 저널, 권(호), 면. DOI |
| 검증 상태 | `[검증됨]` / `[미검증]` + 확인 경로 |
| 표본 | 대상, N, 국가, 산업 |
| 변수 | IV / DV / 매개 / 조절 |
| 측정도구 | 척도명, 원저자, 문항수, α |
| 분석방법 | 회귀 / SEM / PROCESS Model 번호 등 |
| 주요 결과 | 효과 크기와 방향 (β, r, ρ 등 **수치까지**) |
| 한계 | 저자가 밝힌 한계 |
| **본 연구 관련성** | 어느 장·어느 가설의 근거가 되는가 |
| **반대 증거 여부** | 본 연구 주장과 어긋나는가 |

### 3. 읽은 범위를 반드시 기록한다

- `초록만` / `본문 통독` / `방법·결과만` 중 무엇인지 적는다.
- **초록만 읽고 "이 논문은 ~을 발견했다"고 단정하지 마라.**
  초록과 실제 결과가 다른 경우가 드물지 않다.

### 4. 누적한다

`references/문헌매트릭스.md` 에 행을 추가한다. 없으면 만든다.
변수별로 섹션을 나눈다 — 통제위치 / 피드백추구 / 실책관리풍토 / 안전시민행동 / 방법론.

## 주의

- **반대 증거를 별도 섹션에 모아라.** 2장 말미와 5장 한계 절에서 쓰인다.
  이걸 안 모아두면 심사에서 처음 마주치게 된다.
- 국내 문헌은 `tools/kci_search.py` 로 서지를 확보한다.
- 수치(β, r, α)는 **반드시 원문에서 직접** 확인한다. 기억으로 적지 않는다.
