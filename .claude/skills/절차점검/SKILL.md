# 연구수행 절차 점검

논문 **내용**이 아니라 **절차**를 본다.
내용이 아무리 좋아도 절차를 빠뜨리면 학위가 위험해진다.
전체 체크리스트는 `docs/08_연구수행_표준절차_체크리스트.md` 에 있다.

## 먼저 물어야 할 것 — 단계 판정

현재 어느 단계인가? `CLAUDE.md` 의 "현재 단계"를 확인하고,
아래 해당 단계의 **차단 요건(blocker)** 부터 점검한다.

## 단계별 차단 요건

### 자료수집 전 — 🚨 가장 위험한 구간

| 차단 요건 | 확인 |
|---|---|
| **IRB 심의 승인** | 설문조사는 인간대상연구다. **사전심의가 원칙**이고 통상 1개월 이상 걸린다. 승인 없이 수집한 자료는 학위논문에 못 쓸 수 있다. **면제 여부는 연구자가 아니라 IRB 가 판단한다** |
| **연구윤리 교육 이수** | IRB 신청의 전제조건. 미이수면 심의가 시작되지 않는다 |
| **기관 협조** | 공무원 조직 대상 조사는 통상 기관 공문이 필요하다. IRB 와 별개다 |
| **척도 사용 허락** | 번역 시 저자 통지 의무가 있는 척도가 있다 (WLCS) |
| **파일럿 테스트** | 배포 후에는 못 한다. 자체 번안·자체 제작 문항이 있으면 특히 필요 |
| **되돌릴 수 없는 문항** | 집단 식별자, 연속형 측정, 역문항 — 배포 후 추가 불가 (마커변수는 미채택) |

> **이 구간에서 "일단 배포하고 나중에"는 없다.**
> 배포 후 고칠 수 있는 것과 없는 것을 구분해 보고하라.

### 자료수집 중

- 원자료가 `data/raw/` 에 있고 `.gitignore` 로 보호되는가
- **외부 AI 에 원자료를 올리지 않았는가** (절대 금지)
- 배포 부수 / 회수 / 유효 표본이 기록되고 있는가 (4장에 보고해야 함)

### 분석

- 분석계획(`docs/03`)이 **자료를 보기 전에** 확정되었는가
- 결과를 보고 가설을 바꾸지 않았는가 (HARKing)
- 탐색적 분석이 확인적 분석과 구분되어 있는가

### 집필·제출

- 소속 대학원 **논문작성 양식** 확인
- `[미검증]` 문헌이 본문에 인용되지 않았는가 → `citation-verifier` 로 전수 검증
- **표절 검사** (카피킬러 등) 및 대학 기준 충족
- **AI 사용 공시** 규정 확인
- IRB 승인번호 논문 기재

## 점검 명령

```bash
# 원자료 보호 상태
git check-ignore -v data/raw/ && echo "✓ 보호됨"
git ls-files data/ | grep -v gitkeep || echo "✓ 커밋된 원자료 없음"

# 미검증 문헌이 본문에 쓰이는지
grep -rn "\[미검증" docs/*.md | wc -l

# 결재 대기 안건
grep -c "☐" docs/06_교수님_재승인_안건.md
```

## 주의

**세부 규정은 대학·기관마다 다르다.** 일반 기준으로 안내하되,
**"소속 대학원 규정이 우선한다"** 는 점을 반드시 함께 알려라.
확인하지 못한 것을 확인한 것처럼 말하지 마라.
