## 지도교수 논문 (신호철 교수) — 최우선

### ① 이미희·신호철 (2025) — ★★★ 조절변수가 본 연구와 동일

| 항목 | 내용 |
|---|---|
| **서지** | 이미희·신호철 (2025). 포용적 리더십이 구성원의 혁신행동에 미치는 영향: LMX의 매개효과와 지각된 실책관리풍토의 조절효과. **혁신기업연구, 10**(1), 209–227. |
| **영문제목** | The Impact of Inclusive Leadership on Innovative Behavior: The Mediating Effect of LMX and the Moderating Effect of **Perceived Error Management Climate** |
| **DOI** | 10.37297/IER.2025.3.10.1.209 |
| **검증 상태** | **[검증됨]** — Crossref DOI 대조 완료 (2026-09-15) |
| **읽은 범위** | ⚠️ **초록·키워드·목차만.** 본문 미확인 (KISS 유료 ₩7,000) |
| **발행기관** | 사회혁신기업연구원 · KCI 등재 |
| **표본** | 경기 지역 기업 종사자 (인원 수 미확인) |
| **IV** | 포용적 리더십 |
| **매개** | LMX (리더–구성원 교환관계) |
| **조절** | **지각된 실책관리풍토 (Perceived Error Management Climate)** |
| **DV** | 혁신행동 |
| **분석** | **SPSS 22.0** · 타당성·신뢰성·상관분석 → **회귀분석**으로 가설 검증 |
| **주요 결과** | 포용적 리더십 → 혁신행동 정(+)의 영향. LMX 가 매개. **실책관리풍토를 높게 지각한 구성원에서 긍정적 영향력이 더 강화됨** |
| **키워드** | 포용적 리더십, 혁신행동, LMX, 지각된 실책관리풍토, 조절효과 |
| **목차** | Ⅰ서론 Ⅱ이론적 배경 Ⅲ연구방법 Ⅳ분석결과 Ⅴ결론 참고문헌 |

**본 연구와의 관련성 — 매우 높음**

- 본 연구의 조절변수 **「지각된 실책관리풍토」와 용어까지 동일**하다.
- 조절 방향도 같다 — 풍토를 높게 지각할수록 긍정적 효과가 강화된다는 구조.
- **2장 조절변수 절과 3장 조작적 정의에 반드시 인용할 것.**

**⚠️ 원문에서 확인해야 할 것 (현재 미확인)**

- [ ] 실책관리풍토 **측정문항 원문** — 본 연구 8문항과 같은지, 몇 문항을 썼는지
- [ ] **신뢰도(α)** 값
- [ ] 출처를 van Dyck et al.(2005)로 밝혔는지, 다른 번안본을 썼는지
- [ ] 표본 수와 조절효과 검정 방식(상호작용항 투입 방법)

### ② 이원재·신호철 (2026) — ★★★ 매개변수가 본 연구와 동일 + 종단설계

| 항목 | 내용 |
|---|---|
| **서지** | 이원재·신호철 (2026). 상사의 코칭 행동이 직원열의에 미치는 영향: 권력거리 성향의 조절효과 및 심리적 안전감과 피드백 추구 행동의 매개효과. **조직과 인사관리연구, 50**(2), 105–129. |
| **영문제목** | The Effect of Supervisors' Coaching Behavior on Employee Engagement: The Moderating Role of Power Distance Orientation and the Mediating Effects of Psychological Safety and **Feedback-Seeking Behavior** |
| **DOI** | 10.36459/jom.2026.50.2.105 |
| **검증 상태** | **[검증됨]** — Crossref DOI 대조 완료 (2026-09-15) |
| **읽은 범위** | ⚠️ **초록만.** 본문 미확인 (교보스콜라 유료) |
| **발행기관** | 한국인사관리학회 · **국내 조직행동 분야 대표 학술지** |
| **표본** | 군 조직 **복무경력 5년 미만 간부**. 1차 200명 → 최종 **163명** (상사·보직 변경자 제외) |
| **설계** | **3차 종단조사** (2025년 5~6월, 3~4주 간격)<br>1차: 코칭행동·권력거리 / 2차: 심리적 안전감·**피드백 추구 행동** / 3차: 직원열의 |
| **IV** | 상사의 코칭 행동 |
| **매개** | 심리적 안전감, **피드백 추구 행동** |
| **조절** | 권력거리 성향 |
| **DV** | 직원열의 |
| **분석** | **SPSS 27.0 + AMOS 23.0** · 탐색적·확인적 요인분석, 신뢰도 → **위계적 회귀분석** |
| **주요 결과** | ① 코칭행동 → 직원열의 정(+) ② **낮은** 권력거리 성향이 관계를 강화 ③ 심리적 안전감과 피드백 추구 행동이 각각 **부분 매개** |

**본 연구와의 관련성 — 매우 높음**

- 본 연구의 매개변수 **「피드백 추구 행동」과 동일**하다.
- **위계적·고위험 조직(군)** 을 대상으로 했다. 소방 조직과 성격이 유사해
  조직 특성 서술에 참고가 된다.
- **종단설계로 공통방법편향 문제를 설계 단계에서 해결**했다. 본 연구는 현재
  한 시점에 모든 변수를 측정하는 설계라 이 점이 약점인데, 지도교수 연구실이
  이미 해법을 쓰고 있다 → **"시차를 두고 2~3회 조사할까요"를 여쭐 근거.**
- 경력 5년 미만으로 표본을 한정했다. 본 연구의 경력 3구간 설계와 대비해 참고.

**⚠️ 원문에서 확인해야 할 것 (현재 미확인)**

- [ ] **피드백 추구 행동 측정문항 원문** — 본 연구 자체제작 10문항과 비교
- [ ] 출처를 어느 척도로 밝혔는지 (Ashford & Tsui 1991 인지 다른 것인지)
- [ ] **신뢰도(α)** 값
- [ ] 긍정/부정 피드백 추구를 **구분했는지** — 본 연구의 핵심 설계와 직결
- [ ] 종단조사 이탈률 처리 방법
